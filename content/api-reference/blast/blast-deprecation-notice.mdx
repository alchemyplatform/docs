## ⚠️ Deprecation Notice

**Alchemy support for Blast (`blast-mainnet` and `blast-sepolia`) ended on October 26, 2026.** Requests to these endpoints are no longer supported.

## What you need to do

1. Remove any dependencies on the `blast-mainnet` and `blast-sepolia` endpoints from your applications.
2. If you need to continue building on Blast, you will need to use an alternative node provider. See the [official Blast documentation](https://docs.blast.io/) for options.
3. If you are looking for a new EVM-compatible network to build on, explore Alchemy's other [supported chains](/docs/reference/node-supported-chains) for an alternative that fits your needs.

## Need help?

If you have any questions or need assistance, contact us at support@alchemy.com or open a ticket in the [Alchemy Dashboard](https://dashboard.alchemy.com/).
