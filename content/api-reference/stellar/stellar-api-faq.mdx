## What is Stellar?
Stellar is an open-source, decentralized blockchain network designed for fast, low-cost financial transactions and asset tokenization. It features Soroban, a smart contract platform built on Rust and WebAssembly (WASM), offering 5-second finality and a developer-friendly environment for building decentralized applications.

## How do I get started with Stellar?
See the [Stellar API quickstart guide](./stellar-api-quickstart) to start building on Stellar.

## What is the Stellar API?
The Stellar API lets you interact with the Stellar mainnet. You can execute transactions, query onchain data, and interact with the Stellar network using the JSON-RPC standard.

## Is Stellar EVM compatible?
Yes, Stellar is EVM compatible.

## What API does Stellar use?
Stellar uses the JSON-RPC API standard. This API enables blockchain interaction on the Stellar network, letting you read block and transaction data, query chain information, execute smart contracts, and store data onchain.

## What methods are supported on Stellar?
Stellar supports standard Ethereum JSON-RPC methods. Some chain-specific methods may vary. Check the Stellar API endpoints documentation for a complete list.

## What is a Stellar API key?
When you access the Stellar network through a node provider like Alchemy, you use an API key to send transactions and retrieve data. We recommend you [sign up for a free API key](https://dashboard.alchemy.com/signup).

## Which libraries support Stellar?
Common Ethereum libraries like [ethers.js](https://docs.ethers.org/v5/) are compatible with Stellar, given its EVM nature.
