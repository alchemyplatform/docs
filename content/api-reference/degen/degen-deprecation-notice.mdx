## ⚠️ Deprecation Notice

**Alchemy ended support for Degen Mainnet (`degen-mainnet`) on August 31, 2026.** Requests to this endpoint are no longer supported.

Alchemy ended support because the Degen team is sunsetting Degen Chain to focus on social products within the Base ecosystem.

## What you need to do

There is no migration path for Degen Chain, as the network itself has been shut down.

1. If you had assets on Degen Mainnet, bridge them off to Base or another supported network. See the [Degen L3 Bridge](https://bridge.degen.tips/) for details.
2. Remove any dependencies on the `degen-mainnet` endpoint from your applications.
3. If you are building on a Farcaster-adjacent social or Layer-3 chain, explore Alchemy's other [supported chains](/docs/reference/node-supported-chains) for an alternative network that fits your needs.
