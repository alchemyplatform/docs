<Warning>
  Flashblocks are no longer supported on Base Mainnet or Base Sepolia. Denim replaced Flashblocks with canonical 200ms blocks. Flashblocks subscriptions no longer return data, and the `"pending"` block tag no longer provides preconfirmation state.
</Warning>

Use the migration steps below to update your Base integration. For a new integration, start with the [Base API quickstart](/docs/reference/base-api-quickstart).

## Base network availability

| Network | Flashblocks status |
| --- | --- |
| Base Sepolia | Removed when Denim activated on October 21, 2026 at 18:00 UTC. |
| Base Mainnet | Removed when Denim activated on November 5, 2026 at 18:00 UTC. |

## Migrate from Flashblocks to canonical blocks and state

| **Existing integration to update** | Action for Denim |
| --- | --- |
| **`eth_subscribe("newFlashblocks")`** | Use **`eth_subscribe("newHeads")`**. |
| **`eth_subscribe("pendingLogs")`** | Use **`eth_subscribe("logs")`**. |
| **`eth_subscribe("newFlashblockTransactions")`** | Use **`eth_subscribe("newHeads")`**, then fetch transactions for each canonical block. |
| **`"pending"` in `eth_getBalance`, `eth_getTransactionCount`, `eth_call`, `eth_estimateGas`, `eth_simulateV1`, `eth_getBlockByNumber`, `eth_getBlockTransactionCountByNumber`** | Use normal RPC calls to read the **`"latest"`** canonical state / blocks. |
| **`eth_getLogs`** with a range ending at **`"pending"`** | Query through **`"latest"`** or a specific canonical block number. |

<Warning>
  The **`"pending"`** block tag is still accepted, but resolves to the latest canonical block. It no longer exposes Flashblocks preconfirmation state, which has no direct equivalent. The replacements above return canonical data from 200ms blocks.
</Warning>

Check the [Base Flashblocks migration guide](https://docs.base.org/upgrades/denim/migrate-from-flashblocks) for more information.
