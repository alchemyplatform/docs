# Get started with the HyperCore Chain API

Use the intended chain endpoint to query a recent checkpoint with `hl_getLatestBlocks`, persist the last processed block height, then use batch block lookup to repair gaps. The Chain API does not introduce a separate per-chain authentication page; each method's intended request contract is documented with its reference.

For enriched account data and purpose-built market streams, continue with [the HyperCore Data API getting started guide](../../data/hypercore/overview.mdx).
