# Raw and normalized HyperCore blocks

The Chain API treats a block as normalized metadata plus separate command, action, event, and fill collections. It does not force EVM transaction terminology onto HyperCore. Raw source material remains distinct from normalized objects returned by block-oriented APIs.

For data-product queries over normalized historical material, see [historical data](../../../data/hypercore/historical-data/overview.mdx).
