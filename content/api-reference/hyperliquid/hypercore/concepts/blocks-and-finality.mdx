# Blocks and finality

HyperCore block data is modeled as normalized metadata plus raw commands, actions, events, and fills. Do not map these concepts to EVM transactions. The finality signal and correction policy remain service-finalization items.

For indexed historical queries, export datasets, and corrections, see [HyperCore Data API historical data](../../../data/hypercore/historical-data/overview.mdx).
