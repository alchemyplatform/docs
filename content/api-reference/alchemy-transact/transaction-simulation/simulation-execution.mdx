## How does it work?

1. You give us a transaction (unsigned transaction object) 📦
2. We simulate your transaction on our infra ⚡
3. We return a complete list of decoded execution trace and logs 💸

We currently return the following info:

* gas used
* call trace
* logs
* ABI decoded
