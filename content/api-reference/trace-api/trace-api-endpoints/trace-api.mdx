# Endpoints

<Info>
  All Trace API endpoints are only supported on Ethereum Mainnet, Sepolia and Holesky.
</Info>

| Method                                                                     | Description                                                                              |
| -------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- |
| [trace\_call](/docs/reference/trace-call)                                       | Executes the given call and returns a number of possible traces for it.                  |
| [trace\_block](/docs/reference/trace-block)                                     | Returns traces created at given block.                                                   |
| [trace\_get](/docs/reference/trace-get)                                         | Returns trace at given position.                                                         |
| [trace\_filter](/docs/reference/trace-filter)                                   | Returns traces matching given filter.                                                    |
| [trace\_transaction](/docs/reference/trace-transaction)                         | Returns all traces of the given transaction.                                             |
| [trace\_rawTransaction](/docs/reference/trace-rawtransaction)                   | Traces a call without making the call, returning the traces.                             |
| [trace\_replayBlockTransactions](/docs/reference/trace-replayblocktransactions) | Replays all transactions in a block returning the requested traces for each transaction. |
| [trace\_replayTransaction](/docs/reference/trace-replaytransaction)             | Traces a call without making the call, returning the traces.                             |

## What exactly is the Trace API?

Is this a standard RPC endpoint, or is it something Alchemy has developed?

The Trace API is a set of non-standard RPC methods developed by the OpenEthereum team and is now maintained by the Erigon team, not by Alchemy. See [https://openethereum.github.io/JSONRPC-trace-module](https://openethereum.github.io/JSONRPC-trace-module).

## What is the difference between the Ethereum Trace API and Debug API?

The [Trace API](/docs/reference/trace-api-quickstart), which is supported by Erigon node clients, is equivalent to Geth's [Debug API](/docs/reference/debug-api-quickstart). The Debug API offers more API methods than the Trace API and is more widely used because Geth is a more popular Ethereum node client. To compare the [Trace API vs. Debug API](/docs/reference/trace-api-vs-debug-api), read our API comparison guide.
