## ⚠️ Deprecation Notice

**Alchemy will fully deprecate support for Botanix Mainnet (`botanix-mainnet`) and Botanix Testnet (`botanix-testnet`) on August 1, 2026.** After this date, requests to these endpoints will no longer be supported.

Alchemy is ending support because Botanix is shutting down. See the [official Botanix announcement](https://x.com/botanix/status/2064420116578590941) for details.

## What you need to do

There is no migration path for Botanix, as the network itself is being shut down. Before August 1, 2026:

1. Remove any dependencies on Botanix endpoints (`botanix-mainnet` and `botanix-testnet`) from your applications.
2. If you are building on a Bitcoin-native Layer 2, explore Alchemy's other [supported chains](/docs/reference/node-supported-chains) for an alternative network that fits your needs.
