## ⚠️ Deprecation Notice

**Alchemy support for Moonbeam Mainnet (`moonbeam-mainnet`) ended on October 19, 2026.** Requests to this endpoint are no longer supported.

## What you need to do

1. Remove any dependencies on the `moonbeam-mainnet` endpoint from your applications.
2. If you need to continue building on Moonbeam, you will need to use an alternative node provider. See the [official Moonbeam documentation](https://docs.moonbeam.network/) for options.
3. If you are looking for a new EVM-compatible network to build on, explore Alchemy's other [supported chains](/docs/reference/node-supported-chains) for an alternative that fits your needs.

## Need help?

If you have any questions or need assistance, contact us at support@alchemy.com or open a ticket in the [Alchemy Dashboard](https://dashboard.alchemy.com/).
