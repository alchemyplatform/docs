## ⚠️ Deprecation Notice

**Alchemy support for XMTP (`xmtp-ropsten` and `xmtp-mainnet`) ended on October 19, 2026.** Requests to these endpoints are no longer supported.

## What you need to do

1. Remove any dependencies on the `xmtp-ropsten` and `xmtp-mainnet` endpoints from your applications.
2. If you need to continue building on XMTP, you will need to use an alternative node provider. See the [official XMTP documentation](https://docs.xmtp.org/) for options.
3. If you are looking for a new EVM-compatible network to build on, explore Alchemy's other [supported chains](/docs/reference/node-supported-chains) for an alternative that fits your needs.

## Need help?

If you have any questions or need assistance, contact us at support@alchemy.com or open a ticket in the [Alchemy Dashboard](https://dashboard.alchemy.com/).
