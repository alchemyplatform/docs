<Markdown src="../../shared/preview-notice.mdx" />

The NFT API's [Is Spam Contract](/docs/reference/nft-api-endpoints/nft-api-endpoints/nft-spam-endpoints/is-spam-contract-v-3) endpoint also accepts ERC-20 token contract addresses.

The `isSpamContract` result is only `true` or `false`: `true` means the token is spam or a scam; `false` means it is not marked as spam or a scam.

See the linked reference for request parameters, supported networks and response details.
