# Historical data

HyperCore is designed for deep historical coverage. Historical REST, JSON-RPC, and exports document complementary historical-data surfaces. Replay, recovery, corrections, and bulk export are first-class capabilities. Exact coverage and retention will be published as the service is finalized.
