# Networks and endpoints

| Surface | Network | Endpoint |
| --- | --- | --- |
| WebSocket streams | Hyperliquid mainnet | `wss://hypercore-mainnet.g.alchemy.com/v2/<API_KEY>` |
| gRPC (raw blocks, PAYG and Enterprise) | Hyperliquid mainnet | `hypercore-mainnet.g.alchemy.com:443` (TLS) |

Streaming on Hyperliquid testnet isn't available yet. Expanded REST and historical data are coming.

Streams are served from Alchemy-operated nodes in Tokyo, close to Hyperliquid's validators. Clients in other regions add network round-trip time.
