# Stream wallet fills

```js
let lastBlock = await loadLastBlock();   // last fully processed block, or null on first run

function connect() {
  const ws = new WebSocket("wss://hypercore-mainnet.g.alchemy.com/v2/<API_KEY>");
  let lastSeq = 0;                        // seq restarts at 1 on every new subscription

  ws.onmessage = async ({ data }) => {
    const msg = JSON.parse(data);
    if (msg.channel === "connected") {
      ws.send(JSON.stringify({
        method: "subscribe",
        subscriptionId: "wallets",
        subscription: {
          type: "userFills",
          users: ["0x654086857e1fad6dcf05cf6695cce51ea3984268"],
          ...(lastBlock ? { fromBlock: lastBlock + 1 } : {}),
        },
      }));
      return;
    }
    if (msg.subscriptionId !== "wallets" || msg.seq === undefined) return;  // acks, errors

    if (msg.seq !== lastSeq + 1) {
      ws.close();                         // missed a message: reconnect and replay
      return;                             // from lastBlock + 1, the last block fully processed
    }
    lastSeq = msg.seq;

    if (msg.gap) {
      await recordGap(msg.gap);           // range no longer replayable
      lastBlock = msg.gap.toBlock;
      await saveLastBlock(lastBlock);
      return;
    }

    for (const [user, fill] of msg.data.fills) {
      await upsertFill(`${fill.tid}|${user}`, user, fill);  // idempotent, keyed on tid + user
    }
    lastBlock = msg.data.blockNumber;
    await saveLastBlock(lastBlock);       // only after the block's fills are stored
  };

  ws.onclose = () => setTimeout(connect, backoffWithJitter());
}
connect();
```

## Notes

* Save `lastBlock` only after you've stored the block's fills. Advance it only when `seq` is contiguous, so a missed message is always replayed.
* Make fill storage idempotent: write each fill keyed on `tid` plus user (an upsert). If the process stops after storing some fills but before saving `lastBlock`, the block is replayed on restart and the upsert absorbs the duplicates.
* Reconnect promptly. Replay covers roughly the last 30 seconds; a longer outage returns a `gap` for the part that can't be replayed.
* `users` is always an array. Split large wallet sets across several subscriptions.
* Set `aggregateByTime: true` to merge a taker order's partial fills in the same block.
