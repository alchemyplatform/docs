# Stream wallet fills

```js
let lastBlock = await loadLastBlock();   // last fully processed block, or null on first run

function connect() {
  const ws = new WebSocket("wss://hypercore-mainnet.g.alchemy.com/v2/<API_KEY>");
  let lastSeq = 0;                        // seq restarts at 1 on every new subscription
  let stopped = false;                    // set on any failure or close
  let queue = Promise.resolve();          // process messages strictly one at a time

  ws.onmessage = ({ data }) => {
    queue = queue
      .then(() => handle(JSON.parse(data)))
      .catch(() => {                      // missed message or storage failure:
        stopped = true;                   // process nothing further on this connection
        ws.close();                       // and replay from lastBlock + 1 on reconnect
      });
  };

  async function handle(msg) {
    if (stopped) return;
    if (msg.channel === "connected") {
      ws.send(JSON.stringify({
        method: "subscribe",
        subscriptionId: "wallets",
        subscription: {
          type: "userFills",
          users: ["0x654086857e1fad6dcf05cf6695cce51ea3984268"],
          ...(lastBlock !== null ? { fromBlock: lastBlock + 1 } : {}),
        },
      }));
      return;
    }
    if (msg.subscriptionId !== "wallets" || msg.seq === undefined) return;  // acks, errors
    if (msg.seq !== lastSeq + 1) throw new Error("missed message");
    lastSeq = msg.seq;

    if (msg.gap) {
      await recordGap(msg.gap);           // range no longer replayable
      await saveLastBlock(msg.gap.toBlock);
      lastBlock = msg.gap.toBlock;
      return;
    }

    for (const [user, fill] of msg.data.fills) {
      await upsertFill(`${fill.tid}|${user}`, user, fill);  // idempotent, keyed on tid + user
    }
    await saveLastBlock(msg.data.blockNumber);  // only after the block's fills are stored
    lastBlock = msg.data.blockNumber;
  }

  ws.onclose = () => {
    stopped = true;
    setTimeout(connect, backoffWithJitter());
  };
}
connect();
```

## Notes

* Process messages in order, one at a time. WebSocket callbacks don't wait for asynchronous work, so without a queue a later block can be checkpointed before an earlier one is stored.
* Treat any failure as a reason to stop and reconnect: a skipped `seq`, a failed fill write, or a failed checkpoint. Nothing after the failed block is processed, and the reconnect replays from the last saved block.
* Advance `lastBlock` only after it's saved, and only after the block's fills are stored.
* Make fill storage idempotent: write each fill keyed on `tid` plus user (an upsert). A block replayed after a failure or restart then can't be processed twice.
* Reconnect promptly. Replay covers roughly the last 30 seconds; a longer outage returns a `gap` for the part that can't be replayed.
* `users` is always an array. Split large wallet sets across several subscriptions.
* Set `aggregateByTime: true` to merge a taker order's partial fills in the same block.
