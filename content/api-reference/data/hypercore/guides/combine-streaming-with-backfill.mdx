# Combine streaming with backfill

Run a live subscription and persist the checkpoint plus block height. On reconnect, request replay. If replay fails, backfill the missing block range, dedupe domain events, update the checkpoint, then resume live delivery.

## Checkpoint rule
Advance a durable checkpoint only after downstream storage succeeds. Treat a gap, correction, or finality change as a reason to backfill and reconcile.

## Chain API cross-link

When replay cannot bridge a gap, use [Chain API block backfill](../../../hyperliquid/hypercore/guides/retrieve-and-backfill-blocks.mdx).
