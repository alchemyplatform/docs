# HyperCore Data API

Stream Hyperliquid order books and fills in real time from Alchemy-operated nodes, on the same account and API key you use for HyperEVM.

<CardGroup cols={2}>
  <Card title="Quickstart" href="/docs/data/hypercore/getting-started">

  <Card title="WebSocket streams" href="/docs/chains/websockets/hypercore">

  </Card>

The beta covers WebSocket streaming. gRPC, REST, and historical data are planned.

## Common tasks

| I want to… | Use |
| --- | --- |
| Display an order book | [l2Book](/docs/chains/websockets/hypercore/streams/l2-book) |
| Maintain a live order book efficiently | [l2BookDiff](/docs/chains/websockets/hypercore/streams/l2-book-diff) |
| Track best bid and ask | [bbo](/docs/chains/websockets/hypercore/streams/bbo) |
| Track mid prices | [allMids](/docs/chains/websockets/hypercore/streams/all-mids) |
| Analyze order-level depth and queue position | [l4BookUpdates](/docs/chains/websockets/hypercore/streams/l4-book-updates) |
| Watch every trade | [allFills](/docs/chains/websockets/hypercore/streams/all-fills) |
| Watch fills for specific wallets | [userFills](/docs/chains/websockets/hypercore/streams/user-fills) |
| Watch fills from builder-code orders | [builderFills](/docs/chains/websockets/hypercore/streams/builder-fills) |
| Watch liquidations | [liquidationFills](/docs/chains/websockets/hypercore/streams/liquidation-fills) |
| Move from Hyperliquid's public WebSocket | [Migration guide](/docs/chains/websockets/hypercore/migrating-from-hyperliquid-api) |
