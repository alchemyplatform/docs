# HyperCore Data API

Use the HyperCore Data API for real-time market and account streams, enriched reads, historical queries, and bulk datasets.

For raw HyperCore blocks, block-oriented JSON-RPC methods, and protocol-level access, see [the HyperCore Chain API](../../hyperliquid/hypercore/overview.mdx).

## Product shape
HyperCore combines purpose-built real-time streams, native-compatible reads, historical queries, normalized block data, and recovery workflows. Stream details may change before general availability.

## Choose a surface
Use WebSocket for live books, fills, orders, and market context. Use REST for user and historical reads. Use JSON-RPC block methods for deterministic checkpointing and bounded backfills. Use bulk exports for research-scale ingestion.

## Contract notation
Connection details are provided for private-preview access.

## Data API surfaces

This staging area groups REST, WebSocket, historical data, and developer workflows as one Data API product.
