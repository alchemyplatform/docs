# Quickstart

## 1. Get access

HyperCore is available on every Alchemy plan. In the [Alchemy dashboard](https://dashboard.alchemy.com/chains/hypercore), go to **Chains → HyperCore** and enable it for your app. It works with your existing API key. New to Alchemy? [Create an account](https://dashboard.alchemy.com/signup).

## 2. Connect and subscribe

```bash
websocat wss://hypercore-mainnet.g.alchemy.com/v2/<API_KEY>
```

After `{"channel":"connected"}`, send:

```json
{"method":"subscribe","subscriptionId":"eth-top","subscription":{"type":"bbo","coins":["ETH"]}}
```

You'll receive an acknowledgement, a snapshot, then an update whenever the best bid or ask changes:

```json
{"channel":"subscriptionResponse","subscriptionId":"eth-top","data":{"type":"bbo","coins":["ETH"]}}
{"seq":1,"channel":"bbo","subscriptionId":"eth-top","data":{"blockNumber":1183716828,"blockTime":1791996538119,"isSnapshot":true,"books":[{"coin":"ETH","bbo":[{"px":"2442.5","sz":"36.3142","n":7},{"px":"2442.6","sz":"237.042","n":44}]}]}}
```

## 3. Before going to production

HyperCore is free on every plan during launch week. Pricing will be published here before billing starts.

* Reconnect automatically with backoff, and resubscribe after every reconnect. See [connection lifecycle](/docs/chains/websockets/hypercore/connection-lifecycle).
* Track `seq` per subscription to catch missed messages.
* Resume fill streams with `fromBlock`. See [replay and recovery](/docs/chains/websockets/hypercore/replay-and-recovery).
* Filter with `coins` or `users` to keep volume (and cost) down.
* Coming from Hyperliquid's public API? Read [migrating from the Hyperliquid API](/docs/chains/websockets/hypercore/migrating-from-hyperliquid-api).
