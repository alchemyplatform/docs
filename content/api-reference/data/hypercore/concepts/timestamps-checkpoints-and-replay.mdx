# Timestamps, checkpoints, and replay

The intended contract uses Unix milliseconds and opaque checkpoints. Checkpoints order events within a subscription and are not business identifiers. Replay begins after the supplied checkpoint. Clients store and return checkpoints unmodified because their format may change. `cursor` is accepted as an alias for existing client code.
