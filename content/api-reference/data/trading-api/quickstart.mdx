Find USDC pools on Ethereum, prepare an hourly chart, read recent trades, and read wallet profit and loss.

Replace `YOUR_API_KEY` in each cURL command. For TypeScript, use Node.js 22 with TypeScript and `tsx` installed. Copy the TypeScript blocks in order into `trading-quickstart.mts` and run `npx tsx trading-quickstart.mts`.

<Steps>
  <Step title="Get an API key">

Create or select an app in the [Alchemy Dashboard](https://dashboard.alchemy.com/) and copy its API key.

```typescript
export {};

const apiKey = "YOUR_API_KEY";
const base = "https://api.g.alchemy.com/trading/v1/" + encodeURIComponent(apiKey);
const token = "0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48";
const wallet = "0x8e92d28216ac924bbf01f2e7fe4fffd575ec3f17";

async function sleep(ms: number): Promise<void> {
  while (ms > 0) {
    // Respect Node's maximum timer duration without shortening the wait.
    const chunk = Math.min(ms, 2_147_483_647);
    await new Promise<void>((resolve) => setTimeout(resolve, chunk));
    ms -= chunk;
  }
}

async function request<T>(path: string, query: Record<string, string> = {}): Promise<T> {
  const url = new URL(base + path);
  url.search = new URLSearchParams(query).toString();
  for (let attempt = 0; attempt <= 5; attempt++) {
    const response = await fetch(url);
    const body = await response.text();
    if (response.ok) {
      return JSON.parse(body) as T;
    }
    const retryable = response.status === 429 || response.status === 503;
    if (!retryable || attempt === 5) {
      throw new Error("HTTP " + response.status + ": " + body);
    }
    const retryAfter = response.headers.get("retry-after");
    let serverDelay = 0;
    if (retryAfter !== null) {
      const value = retryAfter.trim();
      const parsed = /^\d+$/.test(value)
        ? Number(value) * 1000
        : Date.parse(value) - Date.now();
      if (Number.isFinite(parsed)) {
        serverDelay = Math.max(0, parsed);
      }
    }
    await sleep(Math.max(1000 * 2 ** attempt, serverDelay));
  }
  throw new Error("Retry limit reached.");
}

interface Page<T> {
  data: T[];
  pageKey: string | null;
}

function nextKey(value: unknown, seen: Set<string>): string | null {
  if (value === null) {
    return null;
  }
  if (typeof value !== "string" || value.length === 0 || seen.has(value)) {
    throw new Error("Missing, invalid, or repeated pageKey.");
  }
  seen.add(value);
  return value;
}

console.log("API key configured");
```

  </Step>
  <Step title="Find USDC pools on Ethereum">

Read the first page of pools for USDC. Pool pages contain up to 20 entries. Use the returned `pageKey` to continue with the same filters.

<CodeGroup>

```bash
curl --request GET \
  --url 'https://api.g.alchemy.com/trading/v1/YOUR_API_KEY/tokens/eth-mainnet/0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48/pools'
```

```typescript
interface Pool {
  network: string;
  poolAddress: string;
}
const pools = await request<Page<Pool>>("/tokens/eth-mainnet/" + token + "/pools");
console.log(JSON.stringify(pools.data.map(({ network, poolAddress }) => ({ network, poolAddress })), null, 2));
```

</CodeGroup>

Use a returned pool address for pool-scoped calls. For token market data, request `GET /tokens/{network}/{tokenAddress}`; `include=topPools` adds pool references.

  </Step>
  <Step title="Prepare hourly token OHLCV">

Request up to 24 hourly entries before a given time. Entries are sorted ascending and use ISO 8601 timestamps. Preserve missing intervals as chart gaps. Keep decimal strings for calculations.

<CodeGroup>

```bash
curl --get \
  --url 'https://api.g.alchemy.com/trading/v1/YOUR_API_KEY/tokens/eth-mainnet/0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48/ohlcv' \
  --data-urlencode 'interval=1h' \
  --data-urlencode 'to=2026-11-12T20:00:00Z' \
  --data-urlencode 'limit=24'
```

```typescript
interface OHLCV {
  network: string;
  timestamp: string;
  open: string | null;
  high: string | null;
  low: string | null;
  close: string | null;
  volumeUsd: string | null;
}
interface TokenRef {
  network: string;
  tokenAddress: string;
}
const to = new Date().toISOString();
const from = new Date(Date.parse(to) - 24 * 60 * 60 * 1000).toISOString();
const ohlcv = await request<{ data: { baseToken: TokenRef; quoteToken: TokenRef; ohlcv: OHLCV[] } }>(
  "/tokens/eth-mainnet/" + token + "/ohlcv",
  { interval: "1h", to, limit: "24" },
);
const sorted = [...ohlcv.data.ohlcv].sort((a, b) => Date.parse(a.timestamp) - Date.parse(b.timestamp));
const chartPoints: { timestamp: string; close: string | null }[] = [];
for (const entry of sorted) {
  const previous = chartPoints.at(-1);
  if (previous) {
    for (let gap = Date.parse(previous.timestamp) + 3_600_000; gap < Date.parse(entry.timestamp); gap += 3_600_000) {
      chartPoints.push({ timestamp: new Date(gap).toISOString(), close: null });
    }
  }
  chartPoints.push({ timestamp: entry.timestamp, close: entry.close });
}
console.log(JSON.stringify(chartPoints, null, 2));
```

</CodeGroup>

Example chart output:

```json
[
  {
    "timestamp": "2026-11-12T05:00:00.000Z",
    "close": "0.9996485018430129"
  },
  {
    "timestamp": "2026-11-12T06:00:00.000Z",
    "close": "0.9994207408728889"
  }
]
```

A `null` close in the derived chart marks a gap or an unknown close.

  <Step title="Page through recent trades">

Provide `from` and `to` together, with a maximum window of exactly 30 days. Keep the same range and filters while paging. `pageSize` defaults to 100 and accepts up to 300.

<CodeGroup>

```bash
curl --get \
  --url 'https://api.g.alchemy.com/trading/v1/YOUR_API_KEY/tokens/eth-mainnet/0xa0b86991c6218b36c1d19d4a2e9eb0ce3606eb48/trades' \
  --data-urlencode 'from=2026-11-11T20:00:00Z' \
  --data-urlencode 'to=2026-11-12T20:00:00Z'
```

```typescript
interface Trade {
  network: string;
  id: string;
  txHash: string;
  timestamp: string;
  volumeUsd: string | null;
}
const seen = new Set<string>();
let pageKey: string | null = null;
do {
  const query: Record<string, string> = { from, to };
  if (pageKey !== null) {
    query.pageKey = pageKey;
  }
  const page = await request<Page<Trade>>("/tokens/eth-mainnet/" + token + "/trades", query);
  console.log(JSON.stringify(page, null, 2));
  pageKey = nextKey(page.pageKey, seen);
} while (pageKey !== null);
```

  <Step title="Read lifetime wallet PnL">

`networks` is required. Use only EVM networks, or `solana-mainnet` alone. Pagination applies to token rows; pass the returned `pageKey` unchanged with the same filters to continue.

<CodeGroup>

```bash
curl --get \
  --url 'https://api.g.alchemy.com/trading/v1/YOUR_API_KEY/wallets/0x8e92d28216ac924bbf01f2e7fe4fffd575ec3f17/pnl' \
  --data-urlencode 'networks=eth-mainnet'
```

  <Step title="Handle errors">

The helper retries `429` and `503` up to five times. It honors `Retry-After` seconds or dates and uses exponential backoff. Other HTTP errors, transport errors, malformed JSON, and exhausted retries remain visible.

```json
{
  "error": {
    "code": "UPSTREAM_UNAVAILABLE",
    "message": "Request could not be completed. Retry later."
  }
}
```

Correct `400` request parameters and check resource addresses for `404`. Top-trader data may be unavailable for an otherwise valid token.
