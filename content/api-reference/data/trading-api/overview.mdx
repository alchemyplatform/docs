## Choose General or Premium

General combines lower proposed compute-unit (CU) costs with broader coverage for several capabilities. Premium adds period-based wallet PnL history and a trading summary. Network coverage varies by operation; check the [coverage tables](/docs/data/trading-api/networks-and-conventions) before choosing a variant.

General wallet PnL uses average cost to calculate lifetime realized and unrealized results, split by network and token. Premium reports realized PnL for a selected period, with history, trades, wins, losses, and win rate. **These methodologies differ, so the numbers are not comparable.**

### Proposed compute units

All CU values are proposals awaiting validation. Premium is proposed at 1.75 times General. The names General and Premium and the `/premium` prefix are also provisional.
