## Read market activity

Pool responses include nested tokens and DEX details, with activity grouped by time window. Token market data can include `topPools` references; use the pool endpoints for their details. OHLCV entries use named fields and are ordered by timestamp.

Top traders and holders have coverage that varies by token. Check [Networks and conventions](/docs/data/trading-api/networks-and-conventions) for endpoint coverage and pagination limits.

## Interpret wallet PnL

Wallet PnL is lifetime only and returns `methodology: "average_cost"`. Results include realized and unrealized PnL by network and token. A request must use only EVM networks, or `solana-mainnet` alone.
