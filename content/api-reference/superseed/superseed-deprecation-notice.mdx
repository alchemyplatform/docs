## ⚠️ Deprecation Notice

**Alchemy support for Superseed Mainnet (`superseed-mainnet`) and Superseed Sepolia (`superseed-sepolia`) ended on November 25, 2026.** Requests to these endpoints are no longer supported.

Alchemy ended support because the Superseed team sunset the Superseed L2 chain and moved to Ethereum Mainnet. See the [official Superseed announcement](https://x.com/SuperseedXYZ/status/2079216129059283250) for details.

## What you need to do

There is no migration path for Superseed, as the network itself has been shut down.

1. Remove any dependencies on the `superseed-mainnet` and `superseed-sepolia` endpoints from your applications.
2. If you are building on an OP Stack Layer 2, explore Alchemy's other [supported chains](/docs/reference/node-supported-chains) for an alternative network that fits your needs.
