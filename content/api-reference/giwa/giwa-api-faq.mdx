## What is Giwa?

[Giwa](https://giwa.io/) is an Ethereum Layer 2 optimistic rollup built on the OP Stack by Dunamu, the parent company of Upbit, South Korea's largest cryptocurrency exchange. The name "Giwa" is taken from the traditional Korean clay roof tile, and stands for Global Infrastructure for Web3 Access. Giwa targets one-second block times, full EVM compatibility, and inherits Ethereum's security through data availability on L1.

## What is the Giwa API?

The Giwa API lets your applications connect to a Giwa node on the network. You can read onchain data, submit transactions, and interact with smart contracts using its JSON-RPC endpoints. The API follows the JSON-RPC standard, a stateless, lightweight, remote procedure call (RPC) protocol encoded in JSON.

## Is Giwa EVM compatible?

Yes. Giwa is built on the OP Stack, which means it supports any Ethereum Virtual Machine (EVM) codebase. You can deploy existing Solidity contracts, use the same tools you use for Ethereum, and bridge assets from Ethereum L1 or other interoperable chains to Giwa with minimal changes.

## What is a Giwa API key?

When accessing the Giwa network through a node provider like Alchemy, you use an API key to send transactions and retrieve data from the network.

For the best development experience, we recommend that you [sign up for a free API key](https://dashboard.alchemy.com/signup).

## Which libraries support Giwa?

Common Ethereum libraries such as [viem](https://viem.sh/), [ethers.js](https://docs.ethers.org/), and [web3.js](https://web3js.readthedocs.io/) all support Giwa given its EVM nature. `viem` exports both `giwaSepolia` and `giwaSepoliaPreconf` chain definitions out of the box.

## What programming languages work with Giwa?

Any language that works with Ethereum works with Giwa. Solidity is the primary choice for smart contract development. JavaScript and TypeScript are the most common languages for offchain interactions, while Python, Go, and Rust libraries also work.

## What does Giwa use for gas?

Giwa uses ETH as its native gas token, the same as Ethereum mainnet. Because Giwa is an OP Stack rollup, transaction fees are split into an L2 execution fee and an L1 security fee that covers the cost of publishing transaction data back to Ethereum.

## What is the block time on Giwa?

Giwa targets approximately one-second block times, giving applications near-real-time transaction confirmations while still inheriting Ethereum's security guarantees.

## Which networks does Alchemy support for Giwa?

Alchemy currently supports the following Giwa network:

* **Giwa Sepolia** (chain ID `91342`): `https://giwa-sepolia.g.alchemy.com/v2/{apiKey}`

Giwa mainnet has not yet launched. When it does, we will add mainnet endpoint support here.

## What testnet should I use for Giwa?

Use **Giwa Sepolia** (chain ID `91342`). It is a Layer 2 network connected to Ethereum Sepolia and lets you deploy smart contracts, execute transactions, and rehearse bridging flows at no cost. You can request testnet ETH from public Giwa Sepolia faucets.

## How can I bridge assets between Ethereum and Giwa?

Giwa uses the standard OP Stack bridge to move assets between Ethereum and Giwa. Deposits from L1 to L2 typically confirm within a few minutes; withdrawals from L2 back to L1 include the standard OP Stack challenge period. See the [Giwa documentation](https://docs.giwa.io/) for the current bridge address and step-by-step instructions.

## Which block explorer should I use for Giwa?

Use [Giwa Sepolia Explorer](https://sepolia-explorer.giwa.io/) to look up transactions, addresses, tokens, and contracts on Giwa Sepolia.
