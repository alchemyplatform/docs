The `slotsUpdatesSubscribe` method opens a stream that emits a notification at every step of a slot's lifecycle (`firstShredReceived`, `completed`, `createdBank`, `frozen`, `dead`, `optimisticConfirmation`, `root`). This is more granular than [`slotSubscribe`](/docs/reference/slot-subscribe). Pair it with [`slotsUpdatesUnsubscribe`](#unsubscribe) to stop receiving notifications.

<Warning>
  This subscription is unstable and may change without notice; it is intended primarily for monitoring and validator tooling. The volume of notifications is high.
</Warning>

# Parameters

* None

# Request

<CodeGroup>
  ```shell wscat
  // initiate websocket stream first
  wscat -c wss://solana-mainnet.g.alchemy.com/v2/demo

  // then call subscription
  {"jsonrpc":"2.0","id":1,"method":"slotsUpdatesSubscribe"}
  ```

  ```javascript @solana/web3.js
  import { Connection } from '@solana/web3.js'

  const connection = new Connection(
    'https://solana-mainnet.g.alchemy.com/v2/<-- ALCHEMY APP API KEY -->',
    {
      wsEndpoint: 'wss://solana-mainnet.g.alchemy.com/v2/<-- ALCHEMY APP API KEY -->'
    }
  )

  const subscriptionId = connection.onSlotUpdate((slotUpdate) => {
    console.log('Slot update:', slotUpdate)
  })

  // To unsubscribe later:
  // await connection.removeSlotUpdateListener(subscriptionId)
  ```
</CodeGroup>

# Result

<CodeGroup>
  ```json result
  // subscribe response
  {"jsonrpc":"2.0","result":0,"id":1}

  // notification
  {
    "jsonrpc": "2.0",
    "method": "slotsUpdatesNotification",
    "params": {
      "result": {
        "parent": 75,
        "slot": 76,
        "timestamp": 1625081266243,
        "type": "frozen"
      },
      "subscription": 0
    }
  }
  ```
</CodeGroup>

The `type` field is one of: `firstShredReceived`, `completed`, `createdBank`, `frozen`, `dead`, `optimisticConfirmation`, `root`. The `dead` variant also includes an `err` field.

# Unsubscribe

Use `slotsUpdatesUnsubscribe` with the subscription id returned by `slotsUpdatesSubscribe` to cancel the stream.

* `subscription_id`: `number` - The subscription id to cancel.

<CodeGroup>
  ```shell wscat
  {"jsonrpc":"2.0","id":1,"method":"slotsUpdatesUnsubscribe","params":[0]}
  ```
</CodeGroup>

```json result
{"jsonrpc":"2.0","result":true,"id":1}
```

When using `@solana/web3.js`, call `connection.removeSlotUpdateListener(subscriptionId)` instead of sending the raw JSON-RPC request.
