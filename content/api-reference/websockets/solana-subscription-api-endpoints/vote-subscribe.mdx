The `voteSubscribe` method opens a stream that emits a notification for each new vote observed in gossip. These votes are pre-consensus, so there is no guarantee that they will land in the ledger. Pair it with [`voteUnsubscribe`](#unsubscribe) to stop receiving notifications.

<Warning>
  This subscription is unstable and is disabled by default on most validators. It must be explicitly enabled with the validator's `--rpc-pubsub-enable-vote-subscription` flag for the upstream node to forward votes. Availability and payload shape may change without notice.
</Warning>

# Parameters

* None

# Request

<CodeGroup>
  ```shell wscat
  // initiate websocket stream first
  wscat -c wss://solana-mainnet.g.alchemy.com/v2/demo

  // then call subscription
  {"jsonrpc":"2.0","id":1,"method":"voteSubscribe"}
  ```
</CodeGroup>

<Info>
  `@solana/web3.js` does not currently expose a typed helper for `voteSubscribe`. Use raw JSON-RPC over a WebSocket client (such as `ws` or `wscat`).
</Info>

# Unsubscribe

Use `voteUnsubscribe` with the subscription id returned by `voteSubscribe` to cancel the stream.

* `subscription_id`: `number` - The subscription id to cancel.

<CodeGroup>
  ```shell wscat
  {"jsonrpc":"2.0","id":1,"method":"voteUnsubscribe","params":[0]}
  ```
</CodeGroup>

```json result
{"jsonrpc":"2.0","result":true,"id":1}
```
