The `blockSubscribe` method opens a stream that emits a notification any time a new block reaches the requested commitment level. Pair it with [`blockUnsubscribe`](#unsubscribe) to stop receiving notifications.

<Warning>
  `blockSubscribe` payloads can be very large, especially with `transactionDetails: "full"`. Prefer narrower options (`transactionDetails: "signatures"` or `"none"` and `rewards: false`) when you don't need the full block contents.
</Warning>

# Parameters

* `filter`: filter criteria. Accepts one of:

  * `"all"` - subscribe to all blocks.
  * An object: `{ "mentionsAccountOrProgram": "<pubkey>" }` - subscribe only to blocks that contain a transaction mentioning the provided base-58 encoded pubkey.

* `config` (optional): `object` - Configuration object containing:

  * `commitment`: `string` - One of `confirmed` or `finalized`. Defaults to `finalized`. (`processed` is not supported.)
  * `encoding`: `string` - One of `base58`, `base64`, `base64+zstd`, `jsonParsed`. Defaults to `json`.
  * `transactionDetails`: `string` - One of `full`, `accounts`, `signatures`, `none`. Defaults to `full`.
  * `maxSupportedTransactionVersion`: `number` - Highest transaction version to return.
  * `showRewards`: `boolean` - Whether to populate the `rewards` array. Defaults to `true`.

# Request

<CodeGroup>
  ```shell wscat
  // initiate websocket stream first
  wscat -c wss://solana-mainnet.g.alchemy.com/v2/demo

  // then call subscription
  {"jsonrpc":"2.0","id":1,"method":"blockSubscribe","params":["all",{"commitment":"confirmed","encoding":"base64","showRewards":true,"transactionDetails":"signatures","maxSupportedTransactionVersion":0}]}
  ```

  ```javascript wscat (mentionsAccountOrProgram)
  // subscribe only to blocks that touch the Token program
  {"jsonrpc":"2.0","id":1,"method":"blockSubscribe","params":[{"mentionsAccountOrProgram":"TokenkegQfeZyiNwAJbNbGKPFXCWuBvf9Ss623VQ5DA"},{"commitment":"confirmed","transactionDetails":"signatures","maxSupportedTransactionVersion":0}]}
  ```
</CodeGroup>

<Info>
  `@solana/web3.js` does not currently expose a typed helper for `blockSubscribe`. Use raw JSON-RPC over a WebSocket client (such as `ws` or `wscat`) until upstream helpers ship.
</Info>

# Unsubscribe

Use `blockUnsubscribe` with the subscription id returned by `blockSubscribe` to cancel the stream.

* `subscription_id`: `number` - The subscription id to cancel.

<CodeGroup>
  ```shell wscat
  {"jsonrpc":"2.0","id":1,"method":"blockUnsubscribe","params":[135]}
  ```
</CodeGroup>

```json result
{"jsonrpc":"2.0","result":true,"id":1}
```
