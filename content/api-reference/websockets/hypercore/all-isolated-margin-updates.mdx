# allIsolatedMarginUpdates stream

Carries isolated-margin updates across the available stream scope.

## Subscribe

```json
{
  "method": "subscribe",
  "subscription": {
    "type": "allIsolatedMarginUpdates"
  }
}
```
## Acknowledgement

```json
{
  "channel": "subscriptionResponse",
  "data": {
    "type": "allIsolatedMarginUpdates"
  }
}
```

## Unsubscribe

```json
{
  "method": "unsubscribe",
  "subscription": {
    "type": "allIsolatedMarginUpdates"
  }
}
```

## Payload schema

The payload schema is pending engineering confirmation.
## Resume

To resume a stream, supply `checkpoint` in the subscription object. `cursor` is an accepted alias for `checkpoint` both when it is received in a message and when it is supplied for resumption. The checkpoint is opaque: clients store and return it unmodified, and its format may change.
