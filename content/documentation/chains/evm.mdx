All EVM networks share the same JSON-RPC methods and the same URL format, built from the network's slug:

```
https://{network}.g.alchemy.com/v2
```

For example, `https://base-mainnet.g.alchemy.com/v2`.

* [EVM methods](/docs/chains/ethereum/ethereum-api-endpoints/eth-block-number): JSON-RPC reference.
* [Bundler](/docs/wallets/api-reference/bundler-api/bundler-api-endpoints/eth-send-user-operation): smart account user operations.
* [Node Clients](/docs/documentation/architecture/nodes): the clients we run for each network.
