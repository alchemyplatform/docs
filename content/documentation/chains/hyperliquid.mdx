* **HyperEVM:** EVM JSON-RPC, using the same methods as other [EVM networks](/docs/documentation/chains/evm).
* **Hypercore:** market and account data from the [`/info` endpoint](/docs/chains/websockets/hypercore).

Both use the `hyperliquid-mainnet` network slug.
