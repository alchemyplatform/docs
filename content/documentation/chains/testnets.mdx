We support the testnets of every network we run, with the same APIs as mainnet, so going live is just a change of slug.

<Tip>
Need test tokens? Claim them free from the [Alchemy faucet](#faucets). Enterprise teams can [ask us](mailto:support@alchemy.com) for larger amounts.
</Tip>

| Network | Testnet slugs |
| - | - |
| Ethereum | `eth-sepolia`, `eth-hoodi` |
| Base | `base-sepolia` |
| Arbitrum | `arb-sepolia` |
| Optimism | `opt-sepolia` |
| Polygon | `polygon-amoy` |
| Solana | `solana-devnet` |
| BNB Smart Chain | `bnb-testnet` |
| Avalanche | `avax-fuji` |
| Hyperliquid | `hyperliquid-testnet` |
| Monad | `monad-testnet` |

Call the [Networks endpoint](/docs/reference/node-supported-chains) for every testnet slug.

## Exceptions

A few networks are mainnet only, because their testnet is being retired or isn't live yet:

* Astar
* Dogecoin
* Frax
* Metis
* Mythos
* Scroll
* World Mobile Chain

On the [Enterprise plan](/docs/reference/pricing-plans), [contact us](mailto:support@alchemy.com) if you need larger amounts of testnet tokens, such as for load testing.
</Note>

To claim, your wallet needs:

* At least 0.001 ETH on Ethereum mainnet, or the same on the matching mainnet for non-EVM testnets.
* Some real transactions on mainnet.
* A low testnet balance. Wallets that already hold a lot of testnet tokens can't claim more.
