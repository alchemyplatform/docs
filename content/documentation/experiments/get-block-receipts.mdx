`eth_getBlockReceipts` returns the receipts for every transaction in a block, including status, gas used and logs. It replaces one `eth_getTransactionReceipt` call per transaction.

```bash
curl https://eth-mainnet.g.alchemy.com/v2 \
  --header 'Authorization: Bearer YOUR_ACCESS_TOKEN' \
  --header 'Content-Type: application/json' \
  --data '{"jsonrpc":"2.0","id":1,"method":"eth_getBlockReceipts","params":["latest"]}'
```

It's useful for indexers and explorers that process whole blocks.
