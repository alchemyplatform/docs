Experiments are new features we're testing with early users. They work in production, but their behavior, limits and supported networks may change before they're generally available.

| Experiment | What it does |
| - | - |
| [Fast Confirmation Rule](/docs/documentation/experiments/fast-confirmation) | Confirms Ethereum blocks in seconds instead of minutes |
| [eth\_sendRawTransactionSync](/docs/documentation/experiments/send-raw-transaction-sync) | Sends a transaction and returns its receipt in one call |
| [eth\_getBlockReceipts](/docs/documentation/experiments/get-block-receipts) | Returns every receipt in a block in one call |

Want to try one, or have feedback? [Contact us](mailto:support@alchemy.com).
