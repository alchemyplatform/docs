[Alchemy Collections](https://github.com/alchemyplatform/collections) is an open source set of example requests for [Bruno](https://www.usebruno.com), a free API client that stores requests as files in git. Open a collection, add your token and send requests without writing code.

| Collection | Protocols |
| - | - |
| `alchemy` | JSON-RPC, REST |
| `evm` | JSON-RPC, WebSocket |
| `solana` | JSON-RPC, WebSocket, gRPC |
| `bitcoin` | JSON-RPC, WebSocket, REST |
| `aptos` | gRPC, REST, GraphQL |
| `sui` | JSON-RPC, gRPC, GraphQL |
| `tron` | gRPC |
| `zksync` | JSON-RPC |
| `beacon` | Ethereum Beacon API |

## Get started

**1. Clone the repo**

```bash
git clone https://github.com/alchemyplatform/collections.git
```

**2. Open a collection**

In Bruno, choose **Open Collection** and pick a folder, such as `evm`.

**3. Add your token**

Create a global environment with an `api_key` variable set to your [access token](/docs/how-to-create-access-keys).

**4. Send a request**

Pick any request and click **Send**.

Run `git pull` to get new requests. To add one, open a pull request with a `.bru` file in the right folder.
