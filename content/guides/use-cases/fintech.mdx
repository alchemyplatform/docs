Send and receive stablecoins for payments, payouts and remittances. Gas sponsorship pays network fees, so you never need to hold native tokens like ETH.

* [Stablecoins](/docs/reference/token-api-overview): stablecoin balances for an address (beta).
* [Gas Sponsorship](/docs/wallets/low-level-infra/gas-manager/policy-management/api-endpoints): cover network fees for your users' transactions.
* [Balances](/docs/reference/token-api-overview): all token balances for an address.
* [Webhooks](/docs/reference/webhooks-overview): get notified when incoming payments land.
