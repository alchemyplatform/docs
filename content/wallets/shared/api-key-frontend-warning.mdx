<Warning>
  Anything bundled into client-side code, including your Alchemy API key and gas policy ID, can be read by anyone. This is fine for local development, but for production keep these on your backend and proxy requests through it. See [How do I protect my API key and policy ID in the frontend?](/docs/wallets/resources/faqs#how-do-i-protect-my-api-key-and-policy-id-in-the-frontend) and [API key security best practices](/docs/best-practices-for-key-security-and-management).
</Warning>
