<Warning>
  We strongly recommend against shipping your API key or gas policy ID in your client code. Anyone can read them, which could allow unauthorized use of your gas sponsorship. For production, keep them on your backend and proxy requests through it. See [how to protect your API key and policy ID](/docs/wallets/resources/faqs#how-do-i-protect-my-api-key-and-policy-id-in-the-frontend) and [API key security best practices](/docs/best-practices-for-key-security-and-management).
</Warning>
