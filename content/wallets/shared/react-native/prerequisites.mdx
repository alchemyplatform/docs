## Prerequisites

* React Native version 0.76 or later
* iOS minimum deployment target: 17.0
* [Hermes](https://reactnative.dev/docs/hermes) and [Fabric](https://reactnative.dev/architecture/fabric-renderer) must be enabled (if using Expo these are on by default)
* The authentication package requires React Native's [new architecture](https://reactnative.dev/architecture/landing-page#should-i-use-the-new-architecture-today). For information on how to enable it in your Expo project, see the [documentation](https://docs.expo.dev/guides/new-architecture/).
* The authentication package is incompatible with Expo Go, so you need to use a Development Build. See the [Expo Development Builds documentation](https://docs.expo.dev/guides/local-app-development/)
  for more information.
