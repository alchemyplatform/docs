## Dashboard setup

1. Get your **API key** by creating a new app in your [dashboard](https://dashboard.alchemy.com/apps)

   <Warning>
     Make sure **Ethereum** is enabled for your app under the Networks tab
   </Warning>

2. Activate **smart wallets** in your [Smart Wallets dashboard](https://dashboard.alchemy.com/apps/latest/services/smart-wallets/overview)

   <br />

   a. Apply the config to your app from step 1

   <img src="https://alchemyapi-res.cloudinary.com/image/upload/v1764187298/docs/aa-sdk/images/getting-started/apply-config-to-app.png" alt="apply the config to the app from the first step" style={{ width: "50%" }} />

   <br />

   b. Enable authentication methods you want to support.

   <br />

   <u>**Email auth (OTP)**</u>

   <br />

   If you're using OTP auth, toggle on email and fill in the required fields. For **Redirect
   URL**, pass in the URL of your website (it doesn't get used during
   OTP flows).

   <br />

   <Tip>
     If you're only using OTP auth, you can skip to step 3!
   </Tip>

   <u>**Email auth (Magic Link)**</u>

   * To use email auth in your React Native app, your app needs to be set
     up to handle deep links that can be served via http or https.

   * In production
     scenarios, set up [Android App Links](https://developer.android.com/training/app-links)
     on Android or [Universal Links](https://developer.apple.com/documentation/xcode/supporting-universal-links-in-your-app)
     on iOS to handle deep links.

   * For testing, set up a
     server on [http://localhost:3000](http://localhost:3000/) or any other server
     you control that redirects an incoming request to your app scheme. A sample implementation can be found in the [`example`](https://github.com/alchemyplatform/aa-sdk/blob/main/account-kit/rn-signer/example/redirect-server/index.ts)
     folder of the `React Native Signer` repo.

   * The HTTP or HTTPS URL you set up
     in the previous step needs to be added as the **Redirect URL** in the Smart Wallets
     dashboard.

   * This is the URL that redirects occur to when you use
     the magic link email flow.

   * Optionally stylize the email
     with your brand color and logo.

   <br />

   <img src="https://alchemyapi-res.cloudinary.com/image/upload/v1764187299/docs/aa-sdk/images/getting-started/email-auth-setup.png" alt="configure email auth" style={{ width: "50%" }} />

   <br />

   <u>**Social auth**</u>

   If you want to enable social login, toggle which auth providers
   you want to support.

   * Add your app's deep link as a **whitelisted origin**. This is necessary to handle redirects after authentication.
   * Add the link that your dApp will be running on to the **whitelisted origin** list
   * Optionally enter your own OAuth credentials or use the defaults

   <br />

   <img src="https://alchemyapi-res.cloudinary.com/image/upload/v1764187308/docs/aa-sdk/images/getting-started/social-auth-setup-mobile.png" alt="configure social auth" style={{ width: "50%" }} />

3. Create the config and copy the **API key**
   <img src="https://alchemyapi-res.cloudinary.com/image/upload/v1764187307/docs/aa-sdk/images/getting-started/get-api-key.png" alt="how to copy the api key" style={{ width: "50%" }} />

## Ensure deep linking is properly configured

<Tip>
  If you're using OTP auth, skip this step. Starting with OTP flows
  is recommended as they are easier to set up.
</Tip>

If you plan to use email magic link auth or social auth, ensure deep linking is properly configured in your app.

Depending on whether your app uses `expo-router`, `react-navigation`, or another navigation library, configure deep linking accordingly.

Here are some useful links for common navigation libraries:

* [Expo Router](https://docs.expo.dev/linking/into-your-app/)
* [React Navigation](https://reactnavigation.org/docs/deep-linking/)
