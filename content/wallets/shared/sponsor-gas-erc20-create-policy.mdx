To enable paying gas using an ERC-20 token, create a "Pay gas with any token" policy via the [Gas Manager dashboard](https://dashboard.alchemy.com/gas-manager/policy/create). Customize the policy with the following:

* Receiving address: **you must specify** an address you own where the ERC-20 tokens are sent as gas is paid. The token transfer to this address is orchestrated by the gas sponsorship contract and happens automatically at transaction time.
* Tokens: **you must select** which tokens to accept for gas payment. Learn more [here](https://www.alchemy.com/docs/reference/gas-manager-faqs).
* ERC-20 transfer mode: choose when the token payment occurs.
  * \[Recommended] After: No upfront allowance is required. An approval is signed inside the same transaction batch, and the gas sponsorship pulls the token after the transaction has executed. If that post-execution transfer fails, the entire transaction is reverted and you still pay the gas fee.
  * Before: You must ensure the gas sponsorship already has sufficient allowance -- either through a prior `approve()` transaction or a permit signature -- *before* the transaction is submitted. If the required allowance isn't in place when the transaction is submitted, it is rejected upfront.
* Sponsorship expiry period: this is the period for which the Gas Manager signature and ERC-20 exchange rate remain valid once generated.

You should now have a gas policy created with a policy ID you can use to enable gas payments with ERC-20 tokens.
