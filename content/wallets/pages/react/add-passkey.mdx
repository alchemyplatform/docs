Use this guide to add passkeys as an authentication method in your React app.
You can prompt for a passkey during sign-up or let a signed-in user add one
later from a settings screen.

## Prerequisites

* A React app with Smart Wallets configured
* Authentication already set up in your app. If you still need that, start with
  [React quickstart](/wallets/react/quickstart) and [environment setup](/wallets/react/setup).
* For the second example, a user must already be signed in

## Add a passkey during sign-up

Enable `addPasskeyOnSignup` in your `createConfig` call to prompt for a passkey
as part of sign-up.

```ts twoslash config.ts
// @noErrors
import { createConfig } from "@account-kit/react";
import { sepolia } from "@account-kit/infra";

export const config = createConfig(
  {
    chain: sepolia,
    apiKey: "ALCHEMY_API_KEY",
  },
  {
    illustrationStyle: "outline",
    auth: {
      sections: [[{ type: "email" }], [{ type: "passkey" }]],
      addPasskeyOnSignup: true, // [!code ++]
    },
  },
);
```

When sign-up starts, the UI prompts the user to create a passkey and attach it
to the account.

## Add a passkey after sign-up

Use `useAddPasskey` when you want to add passkeys from a settings page or any
other authenticated screen.

<Warning>
  `useAddPasskey` requires an authenticated user. Call it only after sign-in is
  complete.
</Warning>

```tsx twoslash
import React from "react";
import { useAddPasskey } from "@account-kit/react";

export default function SettingsPage() {
  const { addPasskey, isAddingPasskey } = useAddPasskey();

  return (
    <button
      disabled={isAddingPasskey}
      onClick={async () => {
        await addPasskey();
      }}
    >
      {isAddingPasskey ? "Adding passkey..." : "Add passkey"}
    </button>
  );
}
```

When the button is clicked, the browser opens the passkey creation flow. After
the flow completes, the new passkey is available as a login method for that
account.
