Account Kit, including embedded wallets, signer support, and key management (React SDK, embedded UI components, login methods, etc) is deprecated. 

Use [Wallet APIs](/docs/wallets) for all new integrations. Wallet APIs are signer agnostic and allow for sponsored transactions. We recommend using Privy or another provider for signer support alongside Wallet APIs.

## What Alchemy wallets support today

We still run the transaction layer for embedded wallets. Your signer handles login and keys, and [Wallet APIs](/docs/wallets) handle everything after that: [gas sponsorship](/docs/wallets/transactions/sponsor-gas/overview) on EVM and Solana, batched and parallel calls, automatic retries, [session keys](/docs/wallets/reference/wallet-apis-session-keys), and [EIP-7702](/docs/wallets/transactions/using-eip-7702) upgrades that turn an existing embedded wallet into a smart wallet without changing its address. Wallet APIs work with [Privy](/docs/wallets/third-party/signers/privy) (recommended), [Turnkey](/docs/wallets/third-party/signers/turnkey), [Openfort](/docs/wallets/third-party/signers/openfort), and any viem-compatible signer through a [custom integration](/docs/wallets/third-party/signers/custom-integration).

## Support
