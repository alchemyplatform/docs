Account Kit (v4), including its React SDK, embedded UI components, login methods, MFA flows, and legacy Signer quickstart, is deprecated and its docs have been retired.

Use [Wallet APIs](/docs/wallets) for all new integrations. It covers everything Account Kit did, with a smaller footprint and better support across chains.

## Where things moved

* Get started: [Wallet APIs quickstart](/docs/wallets/quickstart)
* Authentication and login methods: [Wallet integration overview](/docs/wallets)
* External wallets and connectors: [Wallet integration](/docs/wallets)
* Solana wallet flows: [Solana signers](/docs/wallets/solana/signers)
* API reference: [Wallet APIs endpoints](/docs/wallets/smart-wallets)

The [Export private key](/docs/wallets/signer/export-private-key) page remains available for existing integrations.

## Support
