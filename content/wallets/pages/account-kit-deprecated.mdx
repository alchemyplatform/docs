---
title: "[Deprecated] Account Kit"
description: Account Kit (v4) is deprecated. Wallet APIs is the supported successor.
slug: wallets/account-kit-deprecated
---

Account Kit, including embedded wallets, signer support, and key management (React SDK, embedded UI components, login methods, etc) is deprecated. 

Use [Wallet APIs](/docs/wallets) for all new integrations. Wallet APIs are signer agnostic and allow for sponsored transactions. We recommend using Privy or another provider for signer support alongside Wallet APIs.

## Support

For migration questions, please see the migration [guide](/docs/wallets/wallet-integrations/privy/signer-migration-overview).

The [Export private key](/docs/wallets/signer/export-private-key) page remains available for ongoing migrations.
