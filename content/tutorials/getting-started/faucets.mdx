Alchemy runs free testnet faucets at [alchemy.com/faucets](https://www.alchemy.com/faucets).
A faucet sends a small amount of testnet tokens to your wallet. You use these
tokens to pay gas and test transactions on a testnet without spending real money.

You do not need an Alchemy account to use the faucets.

## Eligibility requirements

To prevent abuse, the wallet that receives the tokens must meet these
requirements:

* **Mainnet balance:** the wallet holds at least 0.001 ETH on Ethereum mainnet.
* **Mainnet activity:** the wallet has a history of real transactions on
  Ethereum mainnet. A new wallet with no transactions does not qualify.
* **Low testnet balance:** the wallet does not already hold a large amount of
  tokens on that testnet.

Some networks have different requirements:

* **Hyperliquid Testnet:** the wallet holds at least 0.01 HYPE on Hyperliquid
  mainnet.
* **Humanity Testnet:** there is no mainnet balance or mainnet activity
  requirement. The low testnet balance requirement still applies.

The faucet checks the address that you enter. The mainnet ETH and the mainnet
transactions must be on that same address, not on a different wallet that you
own. ETH on other networks, such as Base or Arbitrum One, does not count.

## Request testnet tokens

<Steps>
  <Step title="Open the faucet for your network">
    Go to [alchemy.com/faucets](https://www.alchemy.com/faucets) and select your
    network.
  </Step>

  <Step title="Enter your wallet address">
    Enter the `0x` address of the wallet that will receive the tokens. The
    faucet does not accept ENS names.
  </Step>

  <Step title="Complete the CAPTCHA">
    Complete the CAPTCHA check.
  </Step>

  <Step title="Send the request">
    Select **Send**. The faucet shows the transaction hash with a link to the
    block explorer.
  </Step>
</Steps>

## Request limits

* You can make 1 request per wallet address on each network per 24 hours
  (or 12 hours on Hyperliquid).
* The limits are separate for each network. A request on Ethereum Sepolia does
  not stop a request on Base Sepolia.
* When you reach the limit, the error message shows the time when you can try
  again.

## Troubleshooting

| Error message                                                                          | What to do                                                                                    |
| -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| Insufficient balance! You need at least 0.001 ETH on Ethereum Mainnet.                 | Add ETH on Ethereum mainnet to the same address.                                              |
| Insufficient activity! Your wallet does not have enough Ethereum Mainnet activity.     | Use a wallet that has a history of transactions on Ethereum mainnet.                          |
| Maximum balance exceeded! Your wallet already has a significant testnet token balance. | Use the tokens that you have.                                                                 |
| Rate limit exceeded. You can request 1 time per 24 hour(s).                            | Try again after the time in the message.                                                      |
| Enter a valid wallet address to get your test tokens                                   | Enter a `0x` address. ENS names are not supported.                                            |
| CAPTCHA verification failed. Please try again.                                         | Complete the CAPTCHA again. If it fails again, refresh the page.                              |
| Insufficient faucet balance                                                            | The faucet is temporarily empty. Try again later. This error does not use your request limit. |
| Transaction is taking longer than expected. Please check the explorer for status.      | The testnet is congested. Open the transaction link in the block explorer.                    |

### The faucet sent the tokens, but my wallet does not show them

* Open the transaction link that the faucet shows and make sure that the
  transaction is confirmed.
* Make sure that your wallet is connected to the correct testnet. For example,
  Sepolia ETH does not show when your wallet is on Ethereum mainnet or Base
  Sepolia.
* When a testnet is congested, the transaction can take more time to confirm.

## Get more testnet tokens

The faucet amount is enough for most development and testing. If your team is
on a paid Alchemy plan and needs more testnet tokens, for example for load
tests or a large deployment, [contact support](https://www.alchemy.com/support)
with the network, the amount, and the receiving address.

## Networks without an Alchemy faucet

* **Solana devnet:** use the [Solana faucet](https://faucet.solana.com/), or run
  `solana airdrop 1 <YOUR_ADDRESS> --url devnet` with the Solana CLI.
* **Test USDC:** use the [Circle faucet](https://faucet.circle.com/).
* **Other testnets:** see the faucet links in the FAQ for that chain in the
  Chains section of these docs. For some layer 2 testnets, you can also get
  Ethereum Sepolia ETH and bridge it to the layer 2 testnet.
