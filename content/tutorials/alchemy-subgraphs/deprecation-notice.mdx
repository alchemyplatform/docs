Alchemy Subgraphs was sunset on December 8, 2025. All subgraph and query endpoints have been discontinued.

## Migrating off Subgraphs

To continue indexing onchain data with The Graph's subgraph framework, migrate your existing subgraphs to a third-party subgraph indexing provider. Any provider that supports The Graph's subgraph specification can host your subgraphs with minimal changes to your existing schema and mapping code.

## Alternative data access on Alchemy

Alchemy continues to support onchain data access across every supported network through our other APIs:

* [Data APIs](/docs/data) — hosted endpoints for token balances, transfers, transaction history, NFT data, and prices.
* [Chain APIs](/docs/chains) — standard JSON-RPC and WebSocket access, including log and event queries via `eth_getLogs` and `eth_subscribe`.

For questions about alternatives, reach out to [support@alchemy.com](mailto:support@alchemy.com).
