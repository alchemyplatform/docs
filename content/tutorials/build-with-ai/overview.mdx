Give your AI agent access to blockchain data, let your coding assistant scaffold dApps with Alchemy APIs, or build fully autonomous onchain workflows — we provide integrations for each use case.

## Pick the right tool

### Alchemy for Agents

[Alchemy for Agents](https://agents.alchemy.com/) lets AI agents access our full API platform **without an API key**. Agents authenticate with a wallet using [SIWE (Sign-In With Ethereum)](https://eips.ethereum.org/EIPS/eip-4361) and pay for compute with USDC via the [x402 payment protocol](https://www.x402.org/).

- No API key required — wallet-based authentication
- Pay-per-use with USDC on Base
- Node RPC, Token API, NFT API, Prices API, Portfolio API, and more
- 100+ supported chains

[Get started with Alchemy for Agents →](docs/alchemy-for-agents)

### Agent Skills

[Alchemy Agent Skills](https://github.com/alchemyplatform/skills) are plug-and-play knowledge packages for AI coding agents. Install them with a single command, and your agent knows how to use every Alchemy API — endpoints, authentication, pagination, error handling, and more.

```bash
npx skills add alchemyplatform/skills --yes
```

- Works with [Claude Code](https://www.anthropic.com/claude-code), [Codex](https://openai.com/index/codex/), [Cursor](https://cursor.com), and other agents that support the skills spec
- Two skills included: `alchemy-api` (API key auth) and `agentic-gateway` (wallet/x402 auth)

[Get started with Agent Skills →](docs/alchemy-agent-skills)

### MCP Server

The [Alchemy MCP Server](https://github.com/alchemyplatform/alchemy-mcp-server) exposes our APIs through the [Model Context Protocol](https://modelcontextprotocol.io/), giving AI tools direct access to blockchain data as tool calls.

- 11+ blockchain tools — token prices, NFT data, transaction history, balances, and more
- 50+ supported chains
- Works with Claude Desktop, Claude Code, Cursor, VS Code Copilot, and Windsurf

[Get started with the MCP Server →](docs/alchemy-mcp-server)

## Compare tools by use case

| I want to... | Use |
|---|---|
| Build an autonomous agent that queries blockchain data with no human in the loop | [Alchemy for Agents](docs/alchemy-for-agents) |
| Give my AI coding agent knowledge of all Alchemy APIs | [Agent Skills](docs/alchemy-agent-skills) |
| Let my IDE copilot query live onchain data during a conversation | [MCP Server](docs/alchemy-mcp-server) |
| Give my coding agent API knowledge *and* live data access | Agent Skills + MCP Server |

These tools are complementary. For example, an agent using **Skills** to understand our API surface can also connect to the **MCP Server** to query live data, or use **Alchemy for Agents** to operate autonomously without a pre-provisioned API key.
