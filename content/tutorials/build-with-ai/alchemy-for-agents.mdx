[Alchemy for Agents](https://agents.alchemy.com/) lets your AI agent access our full API platform without an API key. Your agent authenticates with a wallet using SIWE (Sign-In With Ethereum) and pays for compute with USDC via the x402 payment protocol — no human in the loop.

## How it works

Alchemy for Agents uses two open standards:

- **[SIWE (Sign-In With Ethereum)](https://eips.ethereum.org/EIPS/eip-4361)** — Your agent authenticates by signing a message with its wallet. No username/password or API key required.
- **[x402](https://www.x402.org/)** — An open protocol for HTTP-native payments. When a request requires payment, the server responds with HTTP 402, your agent pays with USDC, and retries the request. Zero protocol fees.

The request flow:

1. Your agent has a wallet funded with USDC on Base
2. Your agent generates a SIWE token to authenticate
3. Your agent sends API requests with the token in the `Authorization` header
4. If the server returns HTTP 402, your agent pays and retries

## Get started

### 1. Set up a wallet

Your agent needs an Ethereum wallet funded with USDC on Base (mainnet or Sepolia).

### 2. Generate a SIWE token

```bash
npx @alchemy/x402 sign-siwe --private-key ./wallet-key.txt
```

### 3. Send a request

Include the token in the `Authorization` header:

```bash
curl https://x402.alchemy.com/eth-mainnet/v2 \
  -H "Authorization: SIWE <your-token>" \
  -H "Content-Type: application/json" \
  -d '{"jsonrpc":"2.0","id":1,"method":"eth_blockNumber","params":[]}'
```

### 4. Handle payments

If you receive an HTTP 402 response, run the payment command:

```bash
npx @alchemy/x402 pay
```

After payment completes, retry the request.

## Gateway endpoints

All endpoints use `x402.alchemy.com` as the base URL instead of the standard `g.alchemy.com`:

| API | Endpoint |
|---|---|
| Node RPC | `https://x402.alchemy.com/{chainNetwork}/v2` |
| NFT API | `https://x402.alchemy.com/{chainNetwork}/nft/v3/*` |
| Prices API | `https://x402.alchemy.com/prices/v1/*` |
| Portfolio API | `https://x402.alchemy.com/data/v1/*` |

These endpoints support the same methods as our standard APIs — the only difference is the authentication and payment mechanism.

## Supported APIs

- **Node RPC** — Standard Ethereum JSON-RPC methods (`eth_*`) plus Alchemy-enhanced methods, across 100+ chains
- **Token API** — Token balances, metadata, and allowances
- **NFT API** — NFT ownership, metadata, sales, and spam detection
- **Transfers API** — Asset transfer history with filtering
- **Prices API** — Spot and historical token prices
- **Portfolio API** — Multi-chain balances and portfolio data
- **Simulation API** — Transaction simulation and outcome prediction

## Handle payments programmatically

For Node.js, you can use the `@x402/fetch` or `@x402/axios` packages to handle the x402 payment flow automatically:

```bash
npm install @x402/fetch
```

These libraries intercept HTTP 402 responses and handle payment for you, so your agent doesn't need to retry requests manually.

## Install as an agent skill

You can also install Alchemy for Agents as an [agent skill](docs/alchemy-agent-skills) so your AI coding agent knows how to use the gateway:

```bash
npx skills add alchemyplatform/skills --yes
```

This installs the `agentic-gateway` skill, which teaches agents the full authentication and payment flow.
