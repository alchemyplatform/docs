<Note title="Alchemy Signer API deprecation">
Alchemy Signer APIs are being sunset. As of June 16, 2026, Alchemy Signer no longer supports new user signups: the `/signup` endpoint no longer accepts new sign-ups, and `/auth-jwt` no longer supports new user signup or wallet pregeneration. Existing users can still log in to be migrated.

For new users, use [Privy](/docs/wallets/third-party/signers/privy) with [Wallet APIs](/docs/wallets/quickstart). The [signer migration overview](/docs/wallets/wallet-integrations/privy/signer-migration-overview) covers the React and JWT / Auth0 auth flows step by step.
</Note>
