## Wallets

* [`wallet_sendPreparedCalls`](https://www.alchemy.com/docs/wallets/api-reference/smart-wallets/wallet-api-endpoints/wallet-send-prepared-calls) now returns `validUntil` for calls using a Gas Sponsorship policy, so you can see when sponsorship expires at submission time.
* [`wallet_getCallsStatus`](https://www.alchemy.com/docs/wallets/api-reference/smart-wallets/wallet-api-endpoints/wallet-get-calls-status) now checks a narrower block range for older calls and has lower latency on several chains, reducing unnecessary “not found” responses when tracking call status.
* Fixed incorrect ERC-20 gas-payment rates returned by [`wallet_prepareCalls`](https://www.alchemy.com/docs/wallets/api-reference/smart-wallets/wallet-api-endpoints/wallet-prepare-calls) for EntryPoint v0.6, helping ensure accurate sponsorship estimates.
* Added preliminary Glamsterdam support for the Ethereum Sepolia Bundler, so teams can begin testing compatibility ahead of the upgrade. [Learn more about the Bundler](https://www.alchemy.com/docs/wallets/transactions/low-level-infra/overview).
