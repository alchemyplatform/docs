<Note title="NFT API endpoint deprecation notice">
Alchemy will shut down a set of NFT API endpoints on **September 30, 2026**. Both the V2 and V3 versions are affected. Until then, these endpoints continue to serve traffic, but new integrations should avoid them and existing callers should migrate before the shutdown.

Deprecated endpoints and their migration paths:

| Deprecated | Migration |
| --- | --- |
| V2 `getCollectionsForOwner`, V3 `getCollectionsForOwner` | Use V3 `getContractsForOwner`. |
| V2 `getCollectionMetadata`, V3 `getCollectionMetadata` | Use V3 `getContractMetadata` (`openSeaMetadata` block). |
| V2 `isHolderOfCollection`, V3 `isHolderOfContract` | Use V3 `getNFTsForOwner` with the `contractAddresses` filter. |
| V2 `getSpamContracts`, V3 `getSpamContracts` | Use V3 `isSpamContract`. Spam flags are also returned inline on V3 `getNFTsForOwner` and V3 `getNFTsForContract`. |
| V2 `searchContractMetadata`, V3 `searchContractMetadata` | Use V3 `getContractMetadata` (by contract address). |
| V2 `summarizeNFTAttributes`, V3 `summarizeNFTAttributes`, V2 `computeRarity`, V3 `computeRarity` | Use V3 `getNFTsForContract` (aggregate collection traits). |
| V2 `invalidateContract`, V3 `invalidateContract` | No action needed. Contract metadata auto-refreshes; V3 `refreshNftMetadata` remains available. |
| V2 `isAirdrop`, V3 `isAirdropNFT` | Derive from the Transfers API (`alchemy_getAssetTransfers`). |
| V2 `getNFTSales`, V3 `getNFTSales` | No direct replacement. Reach out to Alchemy support if you rely on this endpoint. |

See the [NFT API Endpoints overview](https://www.alchemy.com/docs/reference/nft-api-endpoints) for the current supported list.
</Note>
