<Note title="NFT API endpoint deprecation notice">
Alchemy will shut down a set of NFT API endpoints on **September 30, 2026**. Both the V3 endpoints and their V2 counterparts (where they exist) are affected. Until then, these endpoints continue to serve traffic, but new integrations should avoid them.

The following endpoints are being deprecated:

| V3 endpoint | V2 endpoint |
| --- | --- |
| V3 `getNFTSales` | V2 `getNFTSales` |
| V3 `getSpamContracts` | V2 `getSpamContracts` |
| V3 `isAirdropNFT` | V2 `isAirdrop` |
| V3 `isHolderOfContract` | V2 `isHolderOfCollection` |
| V3 `computeRarity` | V2 `computeRarity` |
| V3 `summarizeNFTAttributes` | V2 `summarizeNFTAttributes` |
| V3 `searchContractMetadata` | V2 `searchContractMetadata` |
| V3 `invalidateContract` | V2 `invalidateContract` |
| V3 `getCollectionsForOwner` | — |
| V3 `getCollectionMetadata` | — |

If your app is calling any of these, plan a migration to the remaining NFT API endpoints or reach out to Alchemy support for guidance before September 30, 2026. See the [NFT API Endpoints overview](https://www.alchemy.com/docs/reference/nft-api-endpoints) for the current supported list.
</Note>
