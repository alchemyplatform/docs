<Note title="NFT API endpoint deprecation notice">
Alchemy will shut down a set of NFT API endpoints on **September 30, 2026**. Until then, these endpoints continue to serve traffic, but new integrations should avoid them.

The following endpoints are being deprecated: `getNFTSales`, `getSpamContracts`, `isAirdropNFT`, `isHolderOfContract`, `getCollectionsForOwner`, `computeRarity`, `summarizeNFTAttributes`, `searchContractMetadata`, `getCollectionMetadata`, and `invalidateContract`.

If your app is calling any of these, plan a migration to the remaining NFT API endpoints or reach out to Alchemy support for guidance before September 30, 2026. See the [NFT API Endpoints overview](https://www.alchemy.com/docs/reference/nft-api-endpoints) for the current supported list.
</Note>
