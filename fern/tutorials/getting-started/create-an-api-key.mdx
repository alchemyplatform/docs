> 👋 **New to Alchemy?** Start for free by creating an [Alchemy account](https://alchemy.com/?r=e68b2f77-7fc7-4ef7-8e9c-cdfea869b9b5), then follow this guide to get your API Key!

To use Alchemy's products, you need an API key to authenticate your requests.

You get an API key when you create an app from the dashboard. Follow the steps below to create an app and acquire an API key:

<Steps>

<Step title="Navigate to Apps Tab">

First, navigate to your [Alchemy dashboard](https://dashboard.alchemy.com/signup) and click on the "Apps" tab.

![](https://alchemyapi-res.cloudinary.com/image/upload/v1752502535/docs/Untitled_mrzfsr.jpg)

</Step>

<Step title="Create New App">

Next, click on the "Create new app" button.

![](https://alchemyapi-res.cloudinary.com/image/upload/v1752502701/docs/Untitled_g6gnna.jpg)

</Step>

<Step title="Fill in App Details">

Fill in the details for your new app, this includes specifying a name and description (optional) for it. Then click the "Next" button.

![](https://alchemyapi-res.cloudinary.com/image/upload/v1752502793/docs/Screenshot_2025-07-14_at_7.19.46_AM_prgy4e.png)

</Step>

<Step title="Choose Chains">

Next, you can choose a chain or multiple chains to be supported on your app.

![](https://alchemyapi-res.cloudinary.com/image/upload/v1752502889/docs/Screenshot_2025-07-14_at_7.21.25_AM_iccbgd.png)

</Step>

<Step title="Select Services">

As the last step, you can select what services to activate on your application. You can then select "Create App":

![](https://alchemyapi-res.cloudinary.com/image/upload/v1752503069/docs/Screenshot_2025-07-14_at_7.24.22_AM_naraiy.png)

</Step>

<Step title="Get Your API Key">

Once your app is created, you will be redirected to the app details page, **here you will see your API key in the top right corner**:

![](https://alchemyapi-res.cloudinary.com/image/upload/v1752503366/docs/Untitled_jzcdm1.jpg)

</Step>

<Step title="View Networks and URLs">

The API Key will be enabled on the chains you selected in the previous steps, switch to the "Networks" tab to toggle certain chains and view the request URLs (which contain your generated API key!).

![](https://alchemyapi-res.cloudinary.com/image/upload/v1752503431/docs/Screenshot_2025-07-14_at_7.30.27_AM_zkn64w.png)

</Step>

</Steps>

## 🔑 Next Steps

Now that you have your API Key, follow along to [making your first Alchemy request](/docs/make-your-first-request).
