## Node APIs

Node APIs are the standard JSON-RPC endpoints exposed by blockchain clients. We support **[45+ chains](https://www.alchemy.com/docs/reference/api-overview)** today, with new ones added every month.

### Getting Started:

1. **Grab your API key** from the [Alchemy Dashboard](https://dashboard.alchemy.com/signup).
2. **Make your first request** to any [supported JSON-RPC endpoint](https://www.alchemy.com/docs/reference/chain-apis-overview). For example:

```bash
curl -X POST https://eth-mainnet.g.alchemy.com/v2/apiKey \
     -H "Content-Type: application/json" \
     -d '{
  "jsonrpc": "2.0",
  "method": "eth_blockNumber",
  "params": [],
  "id": 1
}'
```

**Sample Response:**

```json
{
  "jsonrpc": "2.0",
  "id": "1",
  "result": "0x2377"
}
```

This works with any HTTP library — `axios`, `fetch`, and more.

👉 Explore supported chains and methods in our [Node API Reference](https://www.alchemy.com/docs/reference/api-overview).

## Data APIs & Webhooks

### Data APIs

These are high-level APIs built by us to simplify blockchain development. Unlike standard Node APIs, these are powerful abstractions that return rich data in fewer requests.

We provide Data APIs for:

* [NFTs](https://www.alchemy.com/docs/reference/nft-api-quickstart)
* [Tokens](https://www.alchemy.com/docs/reference/token-api-quickstart)
* [Transactions](https://www.alchemy.com/docs/reference/simulation)
* [Prices](https://www.alchemy.com/docs/reference/prices-api-quickstart)
* [Transfers](https://www.alchemy.com/docs/reference/transfers-api-quickstart)
* And more — across multiple networks.

**Example: Get NFTs for an address**

```bash
curl -G https://eth-mainnet.g.alchemy.com/nft/v3/${apiKey}/getNFTsForOwner \
     -d owner=0xd8dA6BF26964aF9D7eEd9e03E53415D37aA96045
```

This endpoint returns all NFTs owned by a wallet — perfect for NFT galleries, dashboards, and marketplaces.

### Webhooks

When polling isn't enough, Webhooks let you receive **real-time on-chain event notifications**. Use them to stream:

* Wallet activity at scale
* Smart contract events
* Full block data (incl. traces)

Webhooks are [**customizable using GraphQL-style filters**](https://www.alchemy.com/docs/reference/custom-webhook) so you only get the data you care about.

📘 Dive into the [Webhooks Quickstart](https://www.alchemy.com/docs/reference/notify-api-quickstart) to get started.

👉 Explore all of our Data capabilities [here](https://www.alchemy.com/docs/reference/api-overview).

## Smart Wallets

Ship smart wallets in minutes with the Account Kit SDK:

* Onboard everyone with email/social login
* Let users transact gas-free with sponsored transactions
* Support invisible signing for users
* Enable automations, permissions and more with powerful wallet policies

Ship for web and mobile with React, React Native, or other JS frameworks.

🎬 Try the [Demo App](https://demo.alchemy.com/) to see what's possible.

### Sample code: Send a gas-free transaction with a smart wallet

```ts
// yarn add @account-kit/infra @account-kit/smart-contracts
import {
  alchemy,
  createAlchemySmartAccountClient,
  sepolia,
} from "@account-kit/infra";
import { createLightAccount } from "@account-kit/smart-contracts";
import { LocalAccountSigner } from "@aa-sdk/core";
import { generatePrivateKey } from "viem/accounts";

const alchemyTransport = alchemy({
  apiKey: "YOUR_API_KEY", // from Alchemy dashboard
});

export const client = createAlchemySmartAccountClient({
  transport: alchemyTransport,
  policyId: "YOUR_POLICY_ID", // create a gas policy in the dashboard
  chain: sepolia,
  account: await createLightAccount({
    chain: sepolia,
    transport: alchemyTransport,
    signer: LocalAccountSigner.privateKeyToAccountSigner(generatePrivateKey()),
  }),
});
```
