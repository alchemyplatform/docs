# Overview

The **Node API** is our implementation of the standard JSON-RPC interface (as defined by Ethereum) and compatible equivalents for non-EVM chains (e.g., Solana, Bitcoin). Use it when you want direct, low-level reads and writes against a blockchain.

Looking for higher-level building blocks?

* For indexed, enriched data (NFTs, tokens, transfers, historical queries), use the **[Data API](/docs/reference/data-overview)**.
* For account-abstraction and smart wallet flows, use the **[Wallet API](/docs/wallets)**.

> **Note:** Chain-specific RPC references (e.g., `eth_call`, `eth_blockNumber`, Solana JSON-RPC) now live under the **[Chains](/docs/reference/chain-apis-overview)** tab.

# When should I use the Node API?

Use the Node API when your app needs direct RPC access—without relying on smart-wallet abstractions or indexed data services.

## Write scenarios

Choose the Node API if:

* Your users send transactions and you’re **not** using Alchemy Smart Wallets.

  * If you **are** using Smart Wallets, see the Wallet API for `sendUserOp`, `estimateUserOpGas`, and other AA flows.

**Common write operations**

* Send native tokens and ERC-20s
* List/buy/sell NFTs
* Submit contract interactions
* Simulate or inspect transactions

**Key RPCs (examples)**

* `eth_sendRawTransaction` — broadcast a serialized, signed TX

> Find chain-specific details in **[Chains](/docs/reference/chain-apis-overview)**.

## Read scenarios

Use the Node API when you need raw blockchain state rather than indexed/enriched results.

**Common read operations**

* Fetch balances and storage
* Call view/pure contract methods
* Filter/poll logs and events
* Estimate gas for a prospective TX

**Key RPCs (examples)**

* `eth_getBalance` — account balance for an address
* `eth_getLogs` — logs matching a filter
* `eth_estimateGas` — gas estimate for a TX
* `eth_call` — execute a read-only call without sending a TX

> Full method lists and chain nuances are in **[Chains](/docs/reference/chain-apis-overview)**.

# Summary

Use the **Node API** when you want a low-level, chain-agnostic interface to:

* Send and simulate transactions
* Read raw blockchain state
* Build tools close to node-level logic

Prefer these for higher-level workflows:

* **[Data API](/docs/reference/data-overview)** — fast, enriched, indexed queries
* **[Wallet API](/docs/wallets)** — smart account & account-abstraction flows
