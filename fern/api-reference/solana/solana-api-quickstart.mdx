## Supported Networks

| Network  | Type        | HTTP  | WSS  | Archive                    | Pruning           |
|----------|-------------|-------|------|----------------------------|-------------------|
| Mainnet  | Production  | Yes   | None | Yes                         | -                 |
| Testnet  | Testnet     | Yes    | -    | 10,964,176 slots           | -                 |
| Devnet   | Testnet     | Yes    | -    | 6,578,505 slots            | -                 |
