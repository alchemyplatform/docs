## 1. Node API

The [Node API](/reference/node-api-overview) gives you low-level access to standard JSON-RPC methods for interacting with blockchains.

Use it for sending transactions, querying blocks and logs, and accessing state. It supports multiple chains; see the [Chain APIs Overview](https://www.alchemy.com/docs/reference/chain-apis-overview) page for the full list.

## 2. Data API

The [Data API](/reference/data-overview) provides structured, indexed data that would be difficult to get via RPC alone.

Use it for NFT metadata, token balances, transaction histories, enriched transfers, and analytics. Optimized for high-volume reads, dashboards, and data-heavy applications.

  <Card title="Transfers API" icon={<img src="https://static.alchemyapi.io/images/docs/right_arow.svg" alt="Transfers API logo" />} href="/reference/prices-api-quickstart">

  <Card title="NFT API" icon={<img src="https://static.alchemyapi.io/images/docs/right_arow.svg" alt="NFT API logo" />} href="/reference/nft-api-quickstart">
