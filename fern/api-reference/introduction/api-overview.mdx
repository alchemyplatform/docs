Alchemy has four main API categories: **Node API**, **Data API**, **Wallets API** and **Rollups**.

  Unlock millions of requests and free archive data on all chains. [Get started for free](https://dashboard.alchemy.com/signup)
</Tip>

# 1. Node API

The [Node API](/reference/node-api-overview) gives you low-level access to standard JSON-RPC methods for interacting with blockchains.

* **Use cases**: Sending transactions, querying blocks and logs, accessing state, and more.
* **Chains supported**: We support 45+ chains, with new ones added every month. See [this page](https://alchemy.com/docs/reference/node-supported-chains) for all chains currently supported in the Node API.

# 2. Data API

The [Data API](/reference/data-overview) provides structured, indexed data that would be difficult to get via RPC alone.

* **Use cases**: NFT metadata, token balances, transaction histories, enriched transfers.
* **Optimized for**: High-volume reads, analytics, and user dashboards.
