# eth\_unsubscribe

Unsubscribe from different Astar event types with a regular RPC call with eth\_unsubscribe as the method and the `subscriptionId` as the first parameter. It returns a bool indicating if the subscription was canceled successfully.

### Parameters

1. Subscription ID, as previously returned from an [eth\_subscribe](/reference/eth-subscribe-astar) call.

### Returns

`true` if a subscription was successfully canceled, or `false` if no subscription existed with the given ID.
