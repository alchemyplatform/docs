Bridging brings users, liquidity, and real economic activity to your rollup.

With Alchemy Rollups, there are two tiers:

1. **Standard Bridge**: Includes the native / canonical bridge bundled with OP Stack, Arbitrum Orbit, etc.
2. **Alchemy Universal Bridge:** In addition to the native bridge, you also get connected to **90+ networks and billions in TVL** on day 1. Includes a hosted bridge UI, bridge aggregation, and free bridge integrations.

# Why do you need bridging?

Every L2 needs a reliable way to move assets in and out.

A native bridge helps move assets to and from your parent chain. However, you can turbocharge liquidity & TVL by making it easy to bridge assets from **any chain**.

That's exactly what the **Alchemy Universal Bridge** delivers: an optimized aggregation layer that integrates Across, LayerZero, Stargate, Relay, Decent, Hyperlane and more behind a single SDK and hosted UI.

# Native Bridge

### OP Stack Standard Bridge

- **Key contracts**: `L1StandardBridge`, `L2StandardBridge`, `OptimismPortal`
- **Flow**
    1. User approves tokens then calls `depositERC20` on `L1StandardBridge`.
    2. Tokens are escrowed on L1; a cross‑domain message moves to L2.
    3. `L2StandardBridge` mints the wrapped ERC‑20 on L2.
    4. Withdrawals reverse the flow after the 7‑day fault‑proof window.
- **Integration**: We spin up a free **Superbridge UI instance** so your users bridge through a polished, branded frontend from day one.

```solidity
IERC20(l1Token).approve(L1_STANDARD_BRIDGE, amount);

L1StandardBridge.depositERC20(
  l1Token,
  l2Token,
  amount,
  200_000,  // l2GasLimit hint
  bytes("") // data
);

```

### Arbitrum Standard Bridge

- **Key contracts**: `L1GatewayRouter`, `L2GatewayRouter`, `StandardERC20Gateway`
- Deposits escrow on L1, create a "retryable ticket," and mint on L2.
- ETH uses the same pattern; gateways handle ERC‑20 routing.
- **Integration**: Your rollup is wired straight into the **Arbitrum Bridge UI** — users can bridge at https://bridge.arbitrum.io/ with no extra work.

```solidity
IL1GatewayRouter(router).outboundTransfer(
  l1Token,
  l2Recipient,
  amount,
  200_000, // maxGas
  0,       // gasPriceBid
  abi.encode(0)
);

```

Why stick with the native bridge?

• Iron‑clad security (inherits L1 consensus)

• Mandatory finality for withdrawals

The native bridge works when week‑long exits are acceptable.
