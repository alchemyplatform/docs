## Wallets

Shipped [Server Wallets](https://www.alchemy.com/docs/wallets/authentication/login-methods/server-wallets). Server wallets enable backend applications to programmatically control wallets using access keys, without requiring interactive authentication. This is perfect for automated systems, batch operations, or when you need to sign transactions from your backend.
