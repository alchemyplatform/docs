## Developer Experience

Added [Yellowstone gRPC](https://www.alchemy.com/docs/reference/yellowstone-grpc-overview) API Reference & docs - a high-performance real-time Solana data streaming interface.

## Rollups

Added Fusaka support on Sepolia - Fusaka is the upcoming Ethereum hard fork introducing key protocol upgrades. Supporting it on Sepolia ensures rollups remain compatible and secure as they post data to Ethereum. Mainnet rollout is expected in December.
