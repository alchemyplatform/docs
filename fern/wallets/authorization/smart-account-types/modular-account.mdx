# Modular Account

Modular Account is Alchemy's advanced smart account implementation that provides extensible functionality through a modular plugin architecture.

## Overview

Modular Account offers advanced features beyond Light Account:

* **Plugin Architecture**: Extend functionality with custom modules
* **Advanced Authorization**: Complex multi-sig and role-based permissions
* **Upgradeable Logic**: Modular upgrade system for new features
* **Custom Validation**: Flexible transaction validation rules

## Key Features

### Plugin System

Add functionality through modules:

* **Session Key Plugins**: Temporary authorization modules
* **Multi-owner Plugins**: Support for multiple account owners
* **Custom Logic**: Application-specific business logic

### Enhanced Security

* Multi-factor authentication integration
* Hardware wallet compatibility
* Custom spending policies

## Adding Plugins

Install and configure plugins:

```typescript
// Add multi-owner plugin
const multiOwnerPlugin = {
  address: "0x..." as Address,
  initData: encodeAbiParameters(
    [{ type: "address[]" }],
    [[owner1, owner2, owner3]]
  ),
};

await client.installPlugin({
  plugin: multiOwnerPlugin,
});
```
