# Light Account

Light Account is Alchemy's flagship smart account implementation, providing a secure and gas-efficient solution for account abstraction.

## Overview

Light Account offers:

* **ERC-4337 Compliance**: Full compatibility with account abstraction standards
* **Gas Optimization**: Efficient bytecode designed for minimal gas consumption
* **Security**: Audited and battle-tested smart contract implementation
* **Flexibility**: Support for various ownership models and upgrade patterns

## Features

### Single Owner Model

Light Account supports a single owner who can:

* Execute transactions
* Add and remove session keys
* Transfer ownership
* Upgrade the account implementation

### Session Keys

Temporary keys that can perform specific actions:

* Time-bound permissions
* Spending limits
* Contract interaction restrictions

## Contract Details

* **Implementation**: Minimal proxy pattern for gas efficiency
* **Upgradability**: UUPS upgradeable pattern
* **Audits**: Audited by leading security firms
* **Gas Costs**: ~100k gas for deployment, ~21k for transfers

## Supported Networks

Light Account is deployed on:

* Ethereum Mainnet
* Sepolia Testnet
* Polygon
* Arbitrum
* Optimism
* Base
