The examples on this page use `@alchemy/wallet-apis` (v5). If you're using `@account-kit/wallet-client` (v4), the client setup looks like this:

```ts title="client.ts (v4)"
import "dotenv/config";
import type { Hex } from "viem";
import { LocalAccountSigner } from "@aa-sdk/core";
import { createSmartWalletClient } from "@account-kit/wallet-client";
import { alchemy, sepolia } from "@account-kit/infra";

const signer = LocalAccountSigner.privateKeyToAccountSigner(process.env.PRIVATE_KEY! as Hex);

export const client = createSmartWalletClient({
  transport: alchemy({ apiKey: process.env.ALCHEMY_API_KEY! }),
  chain: sepolia,
  signer,
  account: signer.address, // required in v4 — use the signer address for EIP-7702
});
```

Other v4 differences:
* **Values** use hex strings: `value: "0x0"` instead of `value: BigInt(0)`
* **Paymaster capability** is called `paymasterService` instead of `paymaster`

See the [full migration guide](/wallets/resources/migration-v5) for a complete cheat sheet.
