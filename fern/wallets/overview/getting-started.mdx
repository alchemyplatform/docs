# Getting Started with Smart Wallets

Welcome to Alchemy's Smart Wallet documentation. This guide will help you integrate smart wallets into your application using Account Kit.

## What are Smart Wallets?

Smart wallets are programmable accounts that enable enhanced functionality beyond traditional externally owned accounts (EOAs). They support features like:

* **Account Abstraction**: Simplified user experiences with gasless transactions
* **Multi-factor Authentication**: Enhanced security with passkeys and social logins
* **Batch Transactions**: Execute multiple operations in a single transaction
* **Custom Authorization**: Implement spending policies and session keys
