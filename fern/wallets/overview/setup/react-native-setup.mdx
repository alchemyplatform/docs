# React Native Setup

Learn how to integrate Account Kit into your React Native application to enable smart wallet functionality with embedded accounts and user authentication.

## Installation

Install the Account Kit React Native SDK and its peer dependencies:

```bash
npm install @alchemy/aa-alchemy @alchemy/aa-core @alchemy/aa-accounts
# or
yarn add @alchemy/aa-alchemy @alchemy/aa-core @alchemy/aa-accounts
```

## Configuration

### 1. Set up your Alchemy API Key

First, obtain your API key from the [Alchemy Dashboard](https://dashboard.alchemy.com/) and configure it in your application.

```typescript
import { AlchemyProvider } from "@alchemy/aa-alchemy";
import { sepolia } from "viem/chains";

const provider = new AlchemyProvider({
  apiKey: "YOUR_ALCHEMY_API_KEY",
  chain: sepolia,
});
```

### 2. Initialize Account Kit

Set up the Account Kit provider with your configuration:

```typescript
import { AccountKitProvider } from "@alchemy/aa-alchemy/react-native";

export default function App() {
  return (
    <AccountKitProvider
      config={{
        apiKey: "YOUR_ALCHEMY_API_KEY",
        chain: sepolia,
      }}
    >
      <YourApp />
    </AccountKitProvider>
  );
}
```

## Basic Usage

### Creating a Smart Account

```typescript
import { useSmartAccountClient } from "@alchemy/aa-alchemy/react-native";
import { useEffect } from "react";

function WalletComponent() {
  const { client, isLoading } = useSmartAccountClient();

  useEffect(() => {
    if (client) {
      console.log("Smart account address:", client.getAddress());
    }
  }, [client]);

  if (isLoading) {
    return <Text>Loading...</Text>;
  }

  return (
    <View>
      <Text>Smart Wallet Ready!</Text>
    </View>
  );
}
```

### User Authentication

Implement user authentication with embedded accounts:

```typescript
import { useAuthModal, useUser } from "@alchemy/aa-alchemy/react-native";

function AuthComponent() {
  const user = useUser();
  const { openAuthModal } = useAuthModal();

  return (
    <View>
      {user ? (
        <Text>Welcome, {user.email}!</Text>
      ) : (
        <Button title="Sign In" onPress={openAuthModal} />
      )}
    </View>
  );
}
```

## Platform-Specific Configuration

### iOS Configuration

Add the following to your `ios/YourApp/Info.plist`:

```xml
<key>NSAppTransportSecurity</key>
<dict>
  <key>NSAllowsArbitraryLoads</key>
  <true/>
</dict>
```

### Android Configuration

Add internet permission to your `android/app/src/main/AndroidManifest.xml`:

```xml
<uses-permission android:name="android.permission.INTERNET" />
```
