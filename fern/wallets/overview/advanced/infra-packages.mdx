# Infrastructure Packages

Account Kit is built on a modular architecture with several core infrastructure packages that handle different aspects of smart wallet functionality. Understanding these packages helps you customize and extend your implementation.

## Core Architecture

Account Kit consists of several key packages:

* **@alchemy/aa-core** - Core abstractions and interfaces
* **@alchemy/aa-alchemy** - Alchemy-specific implementations
* **@alchemy/aa-accounts** - Smart account implementations
* **@alchemy/aa-signers** - Authentication and signing providers

## @alchemy/aa-core

The foundation package providing core abstractions and utilities.

### Key Components

#### SmartAccountClient

The main interface for interacting with smart accounts:

```typescript
import { createSmartAccountClient } from "@alchemy/aa-core";

const client = createSmartAccountClient({
  transport: http("https://eth-sepolia.g.alchemy.com/v2/YOUR_API_KEY"),
  chain: sepolia,
  account: smartAccount,
});
```

**Core methods:**

* `sendUserOperation()` - Send transactions
* `simulateUserOperation()` - Simulate before sending
* `getUserOperationReceipt()` - Get transaction receipt
* `getAddress()` - Get account address

#### BaseSmartContractAccount

Abstract base class for smart account implementations:

```typescript
export abstract class BaseSmartContractAccount implements SmartContractAccount {
  abstract getAccountInitCode(): Promise<Hex>;
  abstract getAddress(): Promise<Address>;
  abstract encodeBatchExecute(txs: BatchUserOperationCallData): Promise<Hex>;
  abstract encodeExecute(tx: UserOperationCallData): Promise<Hex>;
  abstract signUserOperationHash(uoHash: Hex): Promise<Hex>;
}
```

#### Transport Layer

Handles communication with blockchain nodes:

```typescript
import { http, createPublicClient } from "viem";

const transport = http("https://eth-sepolia.g.alchemy.com/v2/YOUR_API_KEY");
const publicClient = createPublicClient({
  chain: sepolia,
  transport,
});
```

## @alchemy/aa-alchemy

Enhanced provider with Alchemy-specific features:

## @alchemy/aa-accounts

Smart account implementations following ERC-4337 standard.

### LightAccount

Optimized smart account implementation:

```typescript
import { createLightAccount } from "@alchemy/aa-accounts";

const lightAccount = await createLightAccount({
  chain: sepolia,
  signer,
  factoryAddress: "0x...", // Optional custom factory
  salt: 0n, // Optional salt for deterministic addresses
});
```

**Features:**

* Gas optimized
* Single owner by default
* Upgradeable to MultiOwnerLightAccount
* ERC-1271 signature validation

### MultiOwnerLightAccount

Extended version with multiple owners:

```typescript
import { createMultiOwnerLightAccount } from "@alchemy/aa-accounts";

const multiOwnerAccount = await createMultiOwnerLightAccount({
  chain: sepolia,
  signer,
  owners: ["0x...", "0x..."], // Multiple owner addresses
});
```

### ModularAccount

Plugin-based account with advanced features:

```typescript
import { createModularAccount } from "@alchemy/aa-accounts";

const modularAccount = await createModularAccount({
  chain: sepolia,
  signer,
  factoryAddress: "0x...",
  plugins: [
    // Plugin configurations
  ],
});
```

## @alchemy/aa-signers

Authentication and signing provider implementations.

### Signer Interface

All signers implement the `SmartAccountSigner` interface:

```typescript
interface SmartAccountSigner {
  getAddress(): Promise<Address>;
  signMessage(message: string | Uint8Array): Promise<Hex>;
  signTypedData(params: SignTypedDataParams): Promise<Hex>;
  authenticate(params: AuthParams): Promise<void>;
}
```

### Available Signers

* **LocalAccountSigner** - Private key signing
* **MagicSigner** - Magic Link authentication
* **Web3AuthSigner** - Social login
* **TurnkeySigner** - Enterprise key management
* **FireblocksSigner** - Institutional custody
* **PrivySigner** - Embedded wallets

## Performance Optimization

### Client Caching

```typescript
// Reuse client instances
const clientCache = new Map<string, SmartAccountClient>();

function getClient(apiKey: string, chain: Chain): SmartAccountClient {
  const cacheKey = `${apiKey}-${chain.id}`;
  
  if (!clientCache.has(cacheKey)) {
    const client = createAlchemySmartAccountClient({
      apiKey,
      chain,
      account,
    });
    clientCache.set(cacheKey, client);
  }
  
  return clientCache.get(cacheKey)!;
}
```

### Batch Operations

```typescript
// Batch multiple operations for efficiency
const batchOperations = [
  { target: "0x...", data: "0x...", value: 0n },
  { target: "0x...", data: "0x...", value: 0n },
  { target: "0x...", data: "0x...", value: 0n },
];

const result = await client.sendUserOperation({
  uo: batchOperations,
});
```
