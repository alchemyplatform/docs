# Whitelabel Setup

Create a fully customized authentication experience that matches your brand by configuring Account Kit's whitelabel options. Remove Alchemy branding and customize the entire user interface.

## Overview

Whitelabel configuration allows you to:

* **Custom branding** - Use your logos, colors, and styling
* **Remove Alchemy branding** - Create a seamless brand experience
* **Custom UI components** - Build your own authentication interface
* **Flexible theming** - Match your application's design system

## Custom Authentication Components

### Building Custom Login Interface

```tsx
import { 
  useAuthenticate, 
  useAuthModal, 
  useUser 
} from "@alchemy/aa-alchemy/react";

function CustomAuthComponent() {
  const user = useUser();
  const { authenticate } = useAuthenticate();
  const { openAuthModal, closeAuthModal } = useAuthModal();
  
  const handleEmailLogin = async (email: string) => {
    try {
      await authenticate({
        type: "email",
        email,
      });
    } catch (error) {
      console.error("Authentication failed:", error);
    }
  };
  
  const handleSocialLogin = async (provider: string) => {
    try {
      await authenticate({
        type: "oauth",
        authProviderId: provider,
      });
    } catch (error) {
      console.error("Social login failed:", error);
    }
  };

  if (user) {
    return (
      <div className="auth-success">
        <h2>Welcome, {user.email}!</h2>
        <button onClick={() => user.logout()}>
          Sign Out
        </button>
      </div>
    );
  }

  return (
    <div className="custom-auth">
      <div className="auth-header">
        <img src="/your-logo.png" alt="YourApp" />
        <h2>Sign in to YourApp</h2>
        <p>Create your smart wallet to get started</p>
      </div>
      
      <form onSubmit={(e) => {
        e.preventDefault();
        const email = e.target.email.value;
        handleEmailLogin(email);
      }}>
        <input
          type="email"
          name="email"
          placeholder="Enter your email"
          className="email-input"
          required
        />
        <button type="submit" className="primary-button">
          Continue with Email
        </button>
      </form>
      
      <div className="divider">
        <span>or</span>
      </div>
      
      <div className="social-buttons">
        <button 
          onClick={() => handleSocialLogin("google")}
          className="social-button google"
        >
          <GoogleIcon />
          Continue with Google
        </button>
        
        <button 
          onClick={() => handleSocialLogin("apple")}
          className="social-button apple"
        >
          <AppleIcon />
          Continue with Apple
        </button>
      </div>
    </div>
  );
}
```

## Environment-Specific Configuration

### Development Environment

```tsx
const developmentConfig = createConfig({
  apiKey: "YOUR_DEV_API_KEY",
  chain: sepolia,
  ui: {
    theme: {
      // Keep Alchemy attribution in development
      showAlchemyAttribution: true,
      primaryColor: "#f59e0b", // Yellow for dev
    },
    modalConfig: {
      title: "YourApp (Development)",
    },
  },
});
```

### Production Environment

```tsx
const productionConfig = createConfig({
  apiKey: "YOUR_PROD_API_KEY",
  chain: mainnet,
  ui: {
    theme: {
      // Remove attribution in production
      showAlchemyAttribution: false,
      primaryColor: "#6366f1",
    },
    modalConfig: {
      title: "YourApp",
      logoUrl: "https://yourdomain.com/logo.png",
    },
  },
});

const config = process.env.NODE_ENV === "production" 
  ? productionConfig 
  : developmentConfig;
```

## Custom Loading States

```tsx
import { useAuthModal } from "@alchemy/aa-alchemy/react";

function CustomLoadingComponent() {
  const { isLoading, error } = useAuthModal();
  
  if (error) {
    return (
      <div className="error-state">
        <ErrorIcon />
        <h3>Authentication Failed</h3>
        <p>{error.message}</p>
        <button onClick={() => window.location.reload()}>
          Try Again
        </button>
      </div>
    );
  }
  
  if (isLoading) {
    return (
      <div className="loading-state">
        <div className="spinner" />
        <p>Setting up your wallet...</p>
      </div>
    );
  }
  
  return null;
}
```

## Best Practices

### Brand Consistency

* **Use consistent colors** across your application and auth flow
* **Match typography** with your existing design system
* **Maintain spacing** that feels natural with your UI
* **Test on all devices** to ensure responsive behavior

### User Experience

* **Clear messaging** - Explain what users are signing up for
* **Progress indicators** - Show loading states during authentication
* **Error handling** - Provide helpful error messages
* **Accessibility** - Ensure keyboard navigation and screen reader support

### Performance

* **Lazy load components** - Only load auth UI when needed
* **Optimize images** - Compress logos and assets
* **Minimize bundle size** - Only include necessary styling
* **Cache configuration** - Reuse config objects when possible
