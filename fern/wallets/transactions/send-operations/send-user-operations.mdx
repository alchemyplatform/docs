# Send User Operations

User Operations are the ERC-4337 standard way to execute transactions with smart wallets. They provide enhanced functionality over traditional transactions.

## Overview

User Operations enable:

* **Gas Abstraction**: Sponsor gas fees for users
* **Batch Transactions**: Execute multiple operations atomically
* **Custom Validation**: Implement complex authorization logic
* **Paymaster Integration**: Use third-party gas payment services

## Basic Usage

<Tabs>
  <Tab title="React">
    ```typescript
    import { useSendUserOperation, useSmartAccountClient } from "@account-kit/react";

    export function SendTransaction() {
      const { client } = useSmartAccountClient();
      const {
        sendUserOperation,
        isSendingUserOperation,
        error
      } = useSendUserOperation({
        client,
        waitForTxn: true
      });

      const handleSend = async () => {
        const result = await sendUserOperation({
          uo: {
            target: "0x..." as Address,
            data: "0x...",
            value: 0n
          }
        });
        
        console.log("Transaction hash:", result.hash);
      };

      return (
        <button 
          onClick={handleSend}
          disabled={isSendingUserOperation}
        >
          {isSendingUserOperation ? "Sending..." : "Send Transaction"}
        </button>
      );
    }
    ```
  </Tab>

  <Tab title="JavaScript">
    ```typescript
    import { createSmartAccountClient } from "@account-kit/core";

    const client = createSmartAccountClient({
      account,
      chain,
      transport: http("https://eth-sepolia.g.alchemy.com/v2/your-api-key"),
    });

    // Send a user operation
    const userOpHash = await client.sendUserOperation({
      target: "0x..." as Address,
      data: "0x...",
      value: 0n
    });

    // Wait for transaction receipt
    const txHash = await client.waitForUserOperationTransaction({
      hash: userOpHash
    });

    console.log("Transaction hash:", txHash);
    ```

</Tabs>

## Error Handling

Handle common errors when sending user operations:

```typescript
try {
  const result = await sendUserOperation({
    uo: {
      target: "0x..." as Address,
      data: "0x...",
      value: 0n
    }
  });
} catch (error) {
  if (error instanceof InsufficientFundsError) {
    console.error("Insufficient funds for transaction");
  } else if (error instanceof UserOperationExecutionError) {
    console.error("User operation execution failed:", error.message);
  } else {
    console.error("Unexpected error:", error);
  }
}
```
